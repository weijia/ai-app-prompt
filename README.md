# ai-app-prompt · 网页应用生成提示词库

一套**可直接复制进豆包 / 元宝对话框**，让其一次性生成可运行网页应用的中文提示词集合。

核心原则：**单文件 HTML、零依赖优先、国内 CDN 可用、localStorage 持久化、中文界面、移动端友好**。

---

## 三步使用法

1. 在下方索引表找到你要的场景，点进对应文件。
2. 把文件里 **「提示词正文」代码块中的内容整段复制**（含占位符替换说明也一起复制效果更好）。
3. 粘贴到豆包 / 元宝，把 `{{占位符}}` 换成你的实际内容，发送 → 得到 `index.html` → 保存后双击浏览器打开即可。

若生成结果不满意，到 [`prompts/08-通用增强`](./prompts/08-通用增强) 挑一条追问词，直接接着对话发送即可，无需重来。

---

## 通用技术要求（每条提示词已内置）

- **单文件交付**：一个完整可运行的 `index.html`，CSS/JS 全部内联，不需要 npm、不需要构建工具。
- **零依赖优先**：能用原生 API 实现的就不引第三方库。
- **图表依赖**：优先 `https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js`，备选 `https://lib.baomitu.com/...`；**禁用 jsdelivr / unpkg**（国内可能不通）。
- **降级兜底**：CDN 加载失败必须降级为原生表格渲染，绝不白屏。
- **数据**：`localStorage` 持久化 + 导出/导入 JSON 按钮。
- **体验**：空状态、输入校验、错误反馈齐全。
- **视觉**：现代简洁、圆角卡片、统一主色、hover/focus 反馈、支持 `prefers-color-scheme` 暗色模式。
- **语言**：界面全中文。

> 依赖源选型理由见 [docs/CDN与依赖选型.md](./docs/CDN与依赖选型.md)，用前建议先看 [docs/使用指南.md](./docs/使用指南.md)。
