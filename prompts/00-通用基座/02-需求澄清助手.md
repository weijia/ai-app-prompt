# 需求澄清助手

> 想法还说不清楚时，先跑这条再生成 · 难度：★☆☆ · 约 1 分钟 · 适用：豆包 / 元宝

## 适用场景

- 脑子里只有个模糊想法（「我想要个记账的东西」）
- 直接生成总是跑偏，回退两三次还没对
- 想把口头需求整理成可复用的需求文档

它不生成代码，只输出一份结构化需求，你可以把结果直接喂给 [01-万能网页应用生成器](./01-万能网页应用生成器.md)。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{原始想法}}` | 你现在能说出来的全部内容，越啰嗦越好 | 「我想做个给家里用的买菜记账，老婆也要能看」 |

## 提示词（中文版）

````text
我打算做一个给自己用的网页小工具，但我的想法还很模糊。请你先不要写代码，只帮我做需求澄清。

【我的原始想法】
{{原始想法}}

请按以下步骤进行：

第一步：信息补全。围绕下面的维度，列出你还不知道、需要向我确认的信息点，最多列 6 个，按重要性排序。每个问题都给我 2-3 个可选答案，我能直接挑。

第二步：给出你的默认假设。对于每个问题，明确说明「如果你不回答，我默认按 X 来处理」，这样即使我一个问题都不答也能继续。

第三步：输出结构化需求文档，格式如下：

## 一句话描述
（不超过 30 字，说明这个工具解决什么问题）

## 目标用户与使用场景
（谁在什么情况下打开它，一次用多久，在手机还是电脑）

## 核心功能清单
1. （动词开头，每条一个原子操作）
2.
3.
（只保留 3 条。若需求确实更复杂，把其余的放到「二期再考虑」）

## 数据结构
| 字段名 | 类型 | 说明 | 是否必填 |

## 页面结构
（用简单 ASCII 或层级列表描述有几个区块，各区块放什么）

## 边界情况
- 空数据：
- 输入非法：
- 数据丢失风险：

## 明确不做的事
（例如：不做登录注册、不做多人同步、不做服务端存储）

第四步：把上面这份需求文档，改写成一段可以直接喂给代码生成模型的提示词，要求包含「单文件 HTML、内联 CSS/JS、零第三方库优先、localStorage 持久化、中文界面、移动端优先、处理空状态」这些约束。

请从第一步开始。
````

## Prompt (English Version)

````text
I want a small personal web tool but my idea is still vague. Do NOT write code yet — help me clarify the requirements first.

[RAW IDEA]
{{RAW_IDEA}}

Follow these steps:

Step 1 — Gap analysis. List the unknowns you need me to confirm, max 6 items ordered by importance. For each, give 2-3 options I can just pick from.

Step 2 — Default assumptions. For each question state "if you don't answer, I'll assume X", so I can proceed even without answering anything.

Step 3 — Structured spec, in this format:

## One-liner
(max 30 words: what problem this solves)

## Target user & context
(who opens it, in what situation, how long per session, phone or desktop)

## Core features
1. (start with a verb, one atomic action each)
2.
3.
(keep exactly 3; put anything else under "Phase 2")

## Data model
| Field | Type | Description | Required |

## Page structure
(describe blocks and their content as a nested list or simple ASCII sketch)

## Edge cases
- Empty data:
- Invalid input:
- Data loss risk:

## Explicit non-goals
(e.g. no auth, no multi-user sync, no server storage)

Step 4 — Rewrite the spec above into a ready-to-paste code-generation prompt that includes these constraints: single-file HTML, inline CSS/JS, zero third-party libs preferred, localStorage persistence, English UI, mobile-first, empty-state handling.

Start with Step 1.
````

## 生成后自检清单

- [ ] 输出里没有大段代码
- [ ] 核心功能不超过 3 条
- [ ] 数据结构表格字段清晰、能直接对应到表单
- [ ] 「明确不做的事」里有登录/服务端这类不该在单文件里做的东西

## 常用追问

1. 「按你的默认假设直接往下走，给我最终版需求文档」
2. 「把核心功能砍到只有 2 条，做成最小可用版本」
3. 「按这份需求直接生成 index.html」
