# 万能网页应用生成器

> 本库母模板，任何需求都能从这里出发 · 难度：★☆☆ · 单次生成约 2–4 分钟 · 适用：豆包 / 元宝

## 适用场景

- 想要的 app 在本库里找不到现成提示词
- 想快速验证一个想法，做出来自己用
- 需要给同事/家人做一个小工具，但不想装环境

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{应用名称}}` | 应用叫啥 | 「家庭值日表」 |
| `{-{使用者与场景}}` | 谁用、在哪用 | 「我用，主要是手机上睡前记录」 |
| `{{核心功能}}` | 3 条以内最关键的功能 | 「添加成员、随机排班、查看本月统计」 |
| `{{数据字段}}` | 每条记录要存什么 | 「成员名、日期、事项、完成状态」 |
| `{{风格偏好}}` | 视觉风格 | 「清爽浅色、圆润卡片、蓝绿主色」 |
| `{{模式}}` | `完整` 或 `精简` | 手机端/怕截断就填 `精简` |

## 用法

整段复制 → 把占位符替换掉 → 粘贴到豆包 / 元宝 → 发送。

## 提示词（中文版）

````text
请作为一名资深前端工程师，为我生成一个可以立刻使用的单文件网页应用。

【应用信息】
- 应用名称：{{应用名称}}
- 使用者与场景：{{使用者与场景}}
- 核心功能（只保留以下 3 项，不要自行增加）：{{核心功能}}
- 数据字段：{{数据字段}}
- 视觉风格：{{风格偏好}}
- 生成模式：{{模式}}

【交付格式要求】
1. 只输出一个完整的 index.html 文件，HTML、CSS、JavaScript 全部内联在同一个文件里，不拆分子文件，不使用 npm、不使用构建工具。
2. 回复结构固定为三部分：
   第一部分：一句话说明这个应用能做什么（不超过 30 字）。
   第二部分：唯一一个 ```html 代码块，里面是完整可运行的代码，绝对不要出现省略号或「此处省略」。
   第三部分：3 行以内「怎么用」说明。

【依赖策略（严格遵守）】
1. 零依赖优先：能用原生 JavaScript 实现的功能，一律不引入第三方库。禁止引入 Vue/React/Tailwind/jQuery/marked/dayjs 等任何 CDN 包。
2. 只有在我明确要求图表时才使用 ECharts，且地址必须是 https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js （版本号必须写死）。禁止使用 jsdelivr、unpkg、cdnjs 等国内可能无法访问的源。
3. 如果使用了任何外链脚本，必须写 onerror 降级：加载失败时用原生 HTML 表格渲染同样的数据，并在页面顶部显示一条黄色提示条，绝不允许白屏。

【工程质量要求】
1. 界面全部使用中文。
2. 移动端优先的响应式布局：包含 <meta name="viewport">，在 375px 宽的手机上必须可用，桌面端再适配更宽布局。
3. 所有数据使用 localStorage 持久化，命名空间前缀使用本应用名称。页面必须提供「导出 JSON」和「导入 JSON」两个按钮。
4. 必须处理三种边界情况：空数据状态（显示引导文案而非空白）、用户输入非法时的校验提示、操作成功/失败的反馈提示。
5. 视觉：现代简洁风格，圆角卡片、统一主色、合理留白、hover 与 focus 有明显反馈。通过 prefers-color-scheme 自动支持暗色模式。
6. 代码规范：关键函数写中文注释，函数职责单一，不使用已废弃的 API，不使用内联 onclick 之外的全局变量污染。

【生成模式约束】
- 若模式为「精简」：总代码量控制在 300 行以内，功能保留核心三项，不要写多余注释和华丽动画。
- 若模式为「完整」：可以适度增加细节，但总代码量不超过 600 行，超出时优先砍掉装饰性功能。

现在开始输出。
````

## Prompt (English Version)

````text
Act as a senior frontend engineer and produce a ready-to-use single-file web app.

[APP SPEC]
- Name: {{APP_NAME}}
- User & context: {{USER_CONTEXT}}
- Core features (keep exactly these 3, do not add more): {{CORE_FEATURES}}
- Data fields: {{DATA_FIELDS}}
- Visual style: {{STYLE}}
- Mode: {{MODE}}   (full | compact)

[DELIVERY]
1. Output ONE complete index.html with HTML/CSS/JS all inline. No npm, no build step, no external files.
2. Reply structure, strictly three parts:
   Part 1: one sentence (max 30 words) describing what the app does.
   Part 2: exactly ONE ```html fenced block containing the complete runnable code. Never use ellipsis or "rest omitted".
   Part 3: usage notes in at most 3 lines.

[DEPENDENCIES]
1. Zero-dependency first: implement everything with vanilla JS. Do NOT load Vue/React/Tailwind/jQuery/marked/dayjs or any CDN bundle.
2. Only if charts are explicitly requested, use ECharts from https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js with a pinned version. Never use jsdelivr, unpkg or cdnjs.
3. Any external script must have an onerror fallback: render the same data as a plain HTML table and show a top banner instead of a blank page.

[QUALITY]
1. UI copy in English.
2. Mobile-first responsive layout with <meta name="viewport">; usable at 375px width, enhanced on desktop.
3. Persist data in localStorage with an app-specific key prefix. Provide Export JSON and Import JSON buttons.
4. Handle empty states, input validation, and success/error feedback.
5. Modern clean visuals: rounded cards, one primary color, generous whitespace, clear hover/focus states, prefers-color-scheme dark mode.
6. Clean commented functions, no deprecated APIs.

[MODE]
- compact: under 300 lines total, keep only the 3 core features, no decorative extras.
- full: richer detail but never above 600 lines; cut decoration before cutting features.

Begin.
````

## 生成后自检清单

- [ ] 双击打开就能用，没有控制台报错
- [ ] 手机宽度下所有按钮都点得到
- [ ] 刷新页面数据还在（localStorage 生效）
- [ ] 导出 JSON 后能再导入回来
- [ ] 清空数据后不是白屏，而是有引导文案
- [ ] 没有任何 jsdelivr / unpkg 的外链
