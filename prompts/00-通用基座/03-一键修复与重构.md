# 一键修复与重构

> 拿一段跑不起来 / 很丑的 HTML，让它救回来 · 难度：★★☆ · 约 2 分钟 · 适用：豆包 / 元宝

## 适用场景

- 之前生成的代码打不开、白屏、功能点了没反应
- 代码能用但结构混乱、改不动
- 想把散落的三件套（html + css + js）合并成一个文件

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{问题描述}}` | 具体症状 | 「点按钮没反应，控制台报 xxx is not defined」 |
| `{{目标}}` | `修复` / `重构` / `合并` / `全部` | 「全部」 |

## 用法

把完整代码贴在 `{{代码}}` 位置；代码很长时先贴出问题的那段，追问再补剩余部分。

## 提示词（中文版）

````text
下面是一段网页代码，请你帮我处理它。

【我遇到的问题】
{{问题描述}}

【任务】
目标：{{目标}}
- 修复：让页面能正常运行，解决报错与失效交互。
- 重构：在功能完全不变的前提下整理代码结构。
- 合并：把 HTML/CSS/JS 合成单一 index.html。
- 全部：依次完成以上三项。

【原代码】
{{代码}}

【修复要求】
1. 先列出你发现的 3-6 个主要问题，每条一句话说明原因（例如「第 42 行使用了未定义的变量 list」）。
2. 再给出修复后的完整 index.html，代码块里必须是不中断的完整代码，禁止省略。
3. 最后用列表说明你改了哪几处、为什么改。

【修复后必须满足】
1. HTML/CSS/JS 全部内联在单一文件中，不使用 npm、不使用构建工具。
2. 只使用原生 JavaScript。如果原代码引了第三方库，请改写成原生实现，或换成国内可访问的 CDN（https://cdn.staticfile.org/ 或 https://lib.baomitu.com/，版本号写死）。若存在 jsdelivr / unpkg 链接，必须替换为上述源并加 onerror 降级处理。
3. 界面全中文，移动端优先响应式。
4. 数据使用 localStorage 持久化，并提供导出/导入 JSON。
5. 处理空状态、输入校验与错误反馈。
6. 现代简洁视觉：圆角卡片、统一主色、hover/focus 反馈、prefers-color-scheme 暗色模式。
7. 不使用已废弃 API，关键函数加中文注释。

【重要】
不要删减任何原有功能来满足行数要求；若代码确实超过 600 行，请原样保留功能，只精简注释与冗余写法。
````

## 生成后自检清单

- [ ] 它先给了问题清单，而不是直接丢代码
- [ ] 修复后的代码能直接替换原文件运行
- [ ] 原功能一个没少
- [ ] 外链全部换成国内源或原生实现

## 常用追问

1. 「只修复报错，不要动样式」
2. 「把它拆成带注释的模块，方便我后续改」
3. 「顺便加移动端适配和数据导出」
