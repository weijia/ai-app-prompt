# 记忆翻牌配对

> 翻转动画 + 步数统计 + 本地排行榜 · 难度：★★☆ · 约 3 分钟

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{卡片主题}}` | 用什么图案 | 「水果 emoji / 自定义文字 / 图片」 |
| `{{难度}}` | 几对 | 「简单 6 对 / 普通 8 对 / 困难 12 对」 |

## 提示词（中文版）

````text
请生成一个「记忆翻牌配对」单文件网页游戏。

【配置】
卡片主题：{{卡片主题}}
难度档位：{{难度}}

【功能要求】
1. 牌组生成：按难度生成 N 对牌，成对内容相同，用 Fisher–Yates 洗牌后铺开；牌面内容默认使用 emoji（如 🍎🍌🍇），也支持用户自定义输入一组文字（逗号分隔，数量不足时自动循环补足并给出提示）。
2. 翻转动画：使用 CSS 3Dtransform（perspective + rotateY + backface-visibility: hidden）实现真翻牌效果，正面显示花色统一的牌背（CSS 渐变图案），背面显示内容。
3. 核心玩法：每次最多翻开两张；相同则标记已配对（保留展示并做一次轻微弹跳），不同则 800ms 后自动翻回；翻牌动画期间禁止再翻其他牌（防止状态错乱）。
4. 计分：记录步数（每次翻两张算 1 步）、用时、错误次数；效率评分可按照「最少步数（= 牌对数） / 实际步数」给出星级。
5. 状态控制：开始/暂停/重开；暂停时牌面遮挡（显示「已暂停」半透明遮罩且禁止翻牌）；计时基于 Date.now() 时间戳，切后台也不失准。
6. 排行榜：按难度分别保存 TOP 5（步数、用时、日期），存 localStorage；可清空排行榜。
7. 提示功能：提供有限次数（默认 3 次）的「偷看 2 秒」按钮，点击后短暂翻开所有牌再盖回，使用后更新剩余次数显示。
8. 胜利表现：全部配对完成后显示用时/步数/星级并提供再来一局；可加一个纯 CSS 的庆祝动效。

【依赖策略】
纯原生 JavaScript + CSS 3D 变换。零第三方库，零 CDN，不使用外部图片。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行操作说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；卡片网格列数随宽度自适应（375px 下建议 4 列），卡片保持正方形且不小于 64px。
2. 数据用 localStorage 持久化，key 前缀 "memory-"，保存排行榜；当前对局不强制保存（重开即弃）。
3. 处理：自定义词库数量不足/重复时的提示、窗口 resize 后卡片重新布局不变形、快速连点时的状态保护。
4. 视觉：现代简洁、牌背图案统一有质感、配对成功有绿色微光反馈、错误时有轻微抖动、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion（直接显示不做 3D 翻转）。
5. 代码总量建议控制在 550 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。翻牌状态机部分加中文注释。
````

## 生成后自检清单

- [ ] 快速连点三张牌不会出现状态错乱
- [ ] 不配对的两张会在 800ms 后自动翻回
- [ ] 12 对困难模式下卡片不会小到点不准
- [ ] 排行榜按难度分开记录且不串
- [ ] 切到后台再回来，计时仍然准确
