# 记忆翻牌配对

> 翻转动画 + 步数统计 + 本地排行榜 · 难度：★★☆ · 约 3 分钟

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{卡片主题}}` | 用什么图案 | 「水果 emoji / 自定义文字 / 图片」 |
| `{{难度}}` | 几对 | 「简单 6 对 / 普通 8 对 / 困难 12 对」 |

## 提示词（中文版）

````text
请生成一个「记忆翻牌配对」单文件网页游戏。

【配置】
卡片主题：{{卡片主题}}
难度档位：{{难度}}

【功能要求】
1. 牌组生成：按难度生成 N 对牌，成对内容相同，用 Fisher–Yates 洗牌后铺开；牌面内容默认使用 emoji（如 🍎🍌🍇），也支持用户自定义输入一组文字（逗号分隔，数量不足时自动循环补足并给出提示）。
2. 翻转动画：使用 CSS 3Dtransform（perspective + rotateY + backface-visibility: hidden）实现真翻牌效果，正面显示花色统一的牌背（CSS 渐变图案），背面显示内容。
3. 核心玩法：每次最多翻开两张；相同则标记已配对（保留展示并做一次轻微弹跳），不同则 800ms 后自动翻回；翻牌动画期间禁止再翻其他牌（防止状态错乱）。
4. 计分：记录步数（每次翻两张算 1 步）、用时、错误次数；效率评分可按照「最少步数（= 牌对数） / 实际步数」给出星级。
5. 状态控制：开始/暂停/重开；暂停时牌面遮挡（显示「已暂停」半透明遮罩且禁止翻牌）；计时基于 Date.now() 时间戳，切后台也不失准。
6. 排行榜：按难度分别保存 TOP 5（步数、用时、日期），存 localStorage；可清空排行榜。
7. 提示功能：提供有限次数（默认 3 次）的「偷看 2 秒」按钮，点击后短暂翻开所有牌再盖回，使用后更新剩余次数显示。
8. 胜利表现：全部配对完成后显示用时/步数/星级并提供再来一局；可加一个纯 CSS 的庆祝动效。

【依赖策略】
纯原生 JavaScript + CSS 3D 变换。零第三方库，零 CDN，不使用外部图片。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行操作说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；卡片网格列数随宽度自适应（375px 下建议 4 列），卡片保持正方形且不小于 64px。
2. 数据用 localStorage 持久化，key 前缀 "memory-"，保存排行榜；当前对局不强制保存（重开即弃）。
3. 处理：自定义词库数量不足/重复时的提示、窗口 resize 后卡片重新布局不变形、快速连点时的状态保护。
4. 视觉：现代简洁、牌背图案统一有质感、配对成功有绿色微光反馈、错误时有轻微抖动、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion（直接显示不做 3D 翻转）。
5. 代码总量建议控制在 550 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。翻牌状态机部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Memory Match" card game.

[CONFIG]
Card theme: {{THEME}}
Difficulty tiers: {{TIERS}}

[FEATURES]
1. Deck generation: N pairs per difficulty, shuffled with Fisher-Yates. Default faces use emoji (🍎🍌🍇); users may also supply custom text (comma separated) — if too few entries, cycle them and notify the user.
2. Flip animation: real 3D flip via CSS transform (perspective + rotateY + backface-visibility: hidden); all card backs share one CSS-gradient pattern, faces show the content.
3. Core loop: at most two cards face up at a time; a match stays revealed with a small bounce pop, otherwise both flip back after 800ms; block flipping other cards while an animation is running to avoid state corruption.
4. Scoring: moves (one move = flipping two cards), elapsed time, mistake count; award stars from min-moves (= pair count) / actual moves.
5. State control: start / pause / restart; pausing overlays the board and blocks flips; time computed from Date.now() timestamps so background throttling doesn't distort it.
6. Leaderboard: per-difficulty TOP 5 (moves, time, date) in localStorage, with a clear button.
7. Hint: a limited (default 3) "peek for 2 seconds" button that reveals every card briefly, decrementing the remaining count.
8. Victory: on full clear show time / moves / stars with a Play again button, optionally with a pure CSS celebration effect.

[DEPENDENCIES]
Vanilla JS + CSS 3D transforms. Zero libraries, zero CDN, no external images.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 control-hint lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; columns adapt to width (4 columns at 375px), cards stay square and at least 64px.
2. localStorage with key prefix "memory-" for leaderboards; the running game need not persist (restart discards it).
3. Warn on too-few or duplicate custom entries, re-layout cleanly on resize without distortion, and guard state against rapid double taps.
4. Modern clean visuals: textured uniform card back, green glow on successful match, slight shake on error, prefers-color-scheme dark mode, respect prefers-reduced-motion (show cards directly without the 3D flip).
5. Aim for about 550 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment the flip state machine.
````
