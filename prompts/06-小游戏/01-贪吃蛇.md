# 贪吃蛇

> 键盘 + 触屏滑动双操控 + 最高分记录 · 难度：★★☆ · 约 2 分钟

## 提示词（中文版）

````text
请生成一个「贪吃蛇」单文件网页游戏。

【配置】
网格大小：{{网格大小}}
难度与速度：{{难度}}

【功能要求】
1. Canvas 绘制棋盘与蛇身；网格线淡色，蛇头与蛇身颜色区分，食物用圆形高亮。
2. 操控三种方式都要支持：
   - 方向键 ↑↓←→ 与 WASD
   - 手机滑动手势（touchstart/touchend 计算位移方向）
   - 屏幕上的方向虚拟摇杆（小屏显示）
3. 核心循环：requestAnimationFrame 渲染 + 基于时间累加的移动间隔（用 deltaTime 控制速度，而不是固定 setInterval，保证不同刷新率设备速度一致）；吃到食物后蛇身 +1 并在随机空格生成新食物。
4. 禁止 180 度反向自杀：按键方向与当前方向相反时忽略该输入（要用「上一次生效方向」而非当前帧方向判断，避免同一帧连按两次导致自杀）。
5. 碰撞处理：撞墙或撞到自己时游戏结束，显示得分、最长长度、是否新纪录，并提供「再来一局」按钮。
6. 计分：每吃一个 +10 分，可根据速度档位给倍率；最高分用 localStorage 保存并显示 TOP 5 排行榜（含日期）。
7. 暂停/继续（空格或按钮）、静音开关、难度切换（慢/中/快对应不同初始间隔与加速度）。
8. 视觉效果：吃到食物时有一次放大反馈动画，蛇身渐变小幅度变色，游戏结束时面板淡入。

【依赖策略】
纯原生 JavaScript + Canvas 2D，零第三方库，零 CDN。音效若实现请用 Web Audio 合成，不外链音频。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行操作说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；画布在 375px 宽下取屏幕宽度的 92% 且保持正方形，禁止页面滚动（touch-action: none 处理画布区域手势，同时保留按钮可点）。
2. 数据用 localStorage 持久化，key 前缀 "snake-"。
3. 处理：窗口 resize 后画布重新适配、页面切到后台自动暂停（visibilitychange）、首帧绘制前显示加载占位。
4. 视觉：现代简洁、深色棋盘 + 亮色蛇身对比清晰、得分 HUD 在顶部、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion（关闭动效但保留功能）。
5. 代码行数控制在 550 行以内，游戏循环与方向校验部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Snake" web game.

[CONFIG]
Grid size: {{GRID}}
Difficulty & speed: {{DIFFICULTY}}

[FEATURES]
1. Draw the board and snake on a Canvas: faint grid lines, distinct head and body colors, food as a bright circle.
2. Three control schemes, all required:
   - arrow keys and WASD
   - touch swipe (compute direction from touchstart/touchend delta)
   - on-screen D-pad shown on small screens
3. Core loop: requestAnimationFrame rendering with a time-accumulator so movement speed derives from deltaTime rather than a fixed setInterval — consistent speed across refresh rates. Eating grows the snake by one and spawns new food in a random empty cell.
4. Prevent instant 180-degree suicide: ignore inputs opposite to the last APPLIED direction (not the current frame's direction, which allows a double-tap death within one frame).
5. Collisions: hitting a wall or itself ends the game — show score, best length, whether it's a new record, and a Play again button.
6. Scoring: +10 per food with a multiplier based on speed tier; persist the high score and show a TOP 5 leaderboard with dates in localStorage.
7. Pause/resume (Space or button), mute toggle, and difficulty switch (slow/medium/fast mapping to different initial intervals and acceleration).
8. Polish: a scale pop when food is eaten, subtle gradient along the body, and a fading game-over panel.

[DEPENDENCIES]
Vanilla JS + Canvas 2D. Zero libraries, zero CDN. If you add sound, synthesize it with Web Audio — no external audio files.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 control-hint lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px the canvas takes 92% of screen width and stays square; apply touch-action: none on the canvas area to stop page scrolling while keeping buttons tappable.
2. localStorage with key prefix "snake-".
3. Re-fit the canvas on resize, auto-pause when the tab loses visibility (visibilitychange), and show a placeholder before the first frame.
4. Modern clean visuals: dark board with high-contrast bright snake, score HUD on top, prefers-color-scheme dark mode, respect prefers-reduced-motion (disable motion, keep functionality).
5. Keep under 550 lines; comment the game loop and direction validation.
````
