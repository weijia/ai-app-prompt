# 产品介绍落地页

> Hero + 卖点 + FAQ + 留资表单 · 难度：★★☆ · 约 3 分钟

## 适用场景

给自己的产品/小店/课程做一个能发出去的单页推广页。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{产品名}}` | 叫什么 | 「晨光手冲咖啡豆」 |
| `{{目标用户}}` | 卖给谁 | 「在家办公、想喝好咖啡的上班族」 |
| `{{转化目标}}` | 希望访客做什么 | 「加微信领优惠券」 |

## 提示词（中文版）

````text
请生成一个「产品介绍落地页」单文件网页应用。

【配置】
产品名：{{产品名}}
目标用户：{{目标用户}}
希望访客完成的行为：{{转化目标}}

【页面结构（从上到下）】
1. 顶部导航：Logo 文字、锚点菜单（特性/价格/常见问题/联系）、右侧主 CTA 按钮；滚动后导航栏加白色背景与阴影（IntersectionObserver 或 scroll 事件实现）。
2. Hero 区：大标题（含产品名）、一句话副标题、主副双 CTA、右侧用纯 CSS 绘制的抽象图形或渐变色块作为视觉（不使用外部图片）。
3. 痛点解决区：左「以前」右「现在」对照排列。
4. 核心特性：6 个图标卡片（图标用内联 SVG 手写，不引图标库），每个含标题与两行说明。
5. 数据背书：3-4 个数字亮点（大字号 + 说明文字）。
6. 使用步骤：3 步竖向流程，带序号圆点。
7. 用户评价：3 条评价卡片（头像用首字母色块占位）。
8. 价格方案：2-3 个套餐卡片，中间一个标记「推荐」并高亮上浮；支持月付/年付切换，年付显示折扣价。
9. FAQ 折叠面板：6 条常见问题，点击展开（details/summary 或 JS 实现，带过渡动画、同一时刻只展开一条）。
10. 留资表单：姓名、联系方式（手机或微信）、需求选择，前端校验（手机号 11 位正则），提交后在页面本地模拟成功提示并写入 localStorage 列表（明确告知不会真实提交到服务器）。
11. 底部：联系方式、二维码占位（纯 CSS 方块图案，不使用二维码库）、版权行。

【动效要求】
元素进入视口时淡入上移（IntersectionObserver + CSS transition），尊重 prefers-reduced-motion；锚点滚动用 scroll-behavior: smooth。

【依赖策略】
零依赖：内联 SVG 图标 + 纯 CSS 图形 + 原生 JS，禁止任何 CDN 与第三方库。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；375px 宽下单列、Hero 区高度不超过一屏、所有文字不溢出、CTA 按钮吸底可点。
2. 表单数据用 localStorage 持久化，key 前缀 "landing-"，页面上提供「查看已收集的线索」按钮（仅本机可见）。
3. 处理：表单空值/格式错误的行内提示、提交后的成功状态、表单校验失败时的滚动定位到第一个错误项。
4. 视觉：现代商业风、统一主色（默认紫蓝渐变）、大量留白、卡片圆角 16px、悬停微交互、prefers-color-scheme 暗色模式。
5. 必须语义化 HTML（header/main/section/footer）、图片有 alt、按钮有 aria-label，保证基础可访问性。
6. 代码行数控制在 800 行以内，各区块用 HTML 注释分隔便于替换文案。
````

## Prompt (English Version)

````text
Generate a single-file "Product Landing Page".

[CONFIG]
Product: {{NAME}}
Target audience: {{AUDIENCE}}
Desired visitor action: {{CTA}}

[PAGE STRUCTURE, top to bottom]
1. Nav bar: text logo, anchor menu (Features / Pricing / FAQ / Contact), primary CTA on the right; gains a white background and shadow after scrolling (via IntersectionObserver or a scroll handler).
2. Hero: big headline containing the product name, one-line subtitle, primary + secondary CTAs, and a CSS-only abstract shape or gradient block on the right (no external images).
3. Problem/solution band: "before" on the left vs "after" on the right.
4. Core features: six icon cards using hand-written inline SVG icons (no icon library), each with a title and two lines of copy.
5. Social proof: 3-4 big-number highlights with captions.
6. How it works: three vertical steps with numbered dots.
7. Testimonials: three review cards with initial-letter color blocks as avatars.
8. Pricing: 2-3 plan cards with the middle one marked "Recommended" and lifted; monthly/yearly toggle where yearly shows the discounted price.
9. FAQ accordion: six questions expanding one at a time with smooth transitions (details/summary or JS).
10. Lead form: name, contact (phone or wechat), need selector, client-side validation (11-digit phone pattern), and a clearly-labeled local success message saying nothing is sent to a real server; store entries in localStorage.
11. Footer: contact details, a CSS placeholder block instead of a real QR code (no QR library), copyright line.

[ANIMATION]
Fade-and-rise on viewport entry via IntersectionObserver + CSS transitions, respect prefers-reduced-motion, and anchor scrolling with scroll-behavior: smooth.

[DEPENDENCIES]
Zero dependencies: inline SVG icons + pure CSS shapes + vanilla JS. No CDN, no third-party libraries at all.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; single column at 375px, hero no taller than one screen, no text overflow, sticky reachable CTA.
2. Persist form leads in localStorage with key prefix "landing-" and provide a "View collected leads" button visible only on this device.
3. Inline validation messages, success state after submit, and auto-scroll to the first invalid field.
4. Modern commercial look: consistent primary color (default purple-blue gradient), generous whitespace, 16px card radius, hover micro-interactions, prefers-color-scheme dark mode.
5. Semantic HTML (header/main/section/footer), alt text on images, aria-label on buttons for baseline accessibility.
6. Keep under 800 lines; separate each section with HTML comments so copy is easy to replace.
````

## 生成后自检清单

- [ ] 所有锚点导航都能滚到对应区块
- [ ] 月付/年付切换价格正确
- [ ] 表单留空提交会提示且不刷新页面
- [ ] 手机上 Hero 不超过一屏、按钮能点到
- [ ] 代码里没有任何外部字体/图片/库链接
