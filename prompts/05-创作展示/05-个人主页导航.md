# 个人主页导航

> 头像 + 简介 + 多平台链接 + 二维码分享 · 难度：★☆☆ · 约 2 分钟

## 适用场景

做一个类似 Linktree 的个人聚合页，放简历、公众号、作品链接，二维码发出去。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{昵称}}` | 展示的名字 | 「阿哲」 |
| `{{一句话介绍}}` | 简介 | 「前端工程师 / 业余摄影师」 |
| `{{链接清单}}` | 要放的链接 | 「博客、GitHub、公众号、小红书、邮箱」 |

## 提示词（中文版）

````text
请生成一个「个人主页导航」单文件网页应用。

【配置】
昵称：{{昵称}}
一句话介绍：{{一句话介绍}}
需要展示的链接：{{链接清单}}

【功能要求】
1. 头部：头像（Canvas 压缩为圆形 base64，支持本地选择）、昵称、一句话介绍、可选认证小图标（内联 SVG）。
2. 链接列表：每个链接含标题、URL、图标（用平台首字母或内联 SVG 简易图形，禁止图标库）、可拖拽排序、可编辑删除、可开关显示。
3. 分组：支持创建 2-3 个分组（如「我的作品」「联系我」「社交」），每组一个标题 + 一组链接。
4. 点击统计：每次点击记录次数到 localStorage，编辑模式下可查看每个链接的点击数（展示视图隐藏统计）。
5. 二维码：生成当前个人主页 URL 的二维码。若不方便内联完整 QR 编码器，则退而求其次——用一个「二维码占位 + 提示用户使用浏览器分享/保存书签」的方案，并在页面上说明原因。优先尝试内联精简 QR 编码器（必须能被手机扫出）。
6. 主题：提供 4 套预设主题（纯白极简、暗夜、渐变紫、奶油暖色），一键切换；支持自定义主色。
7. 导出：导出只读版 HTML（数据内联、只读展示），便于部署到任意静态托管或直接发给朋友。

【依赖策略】
纯原生 JavaScript + Canvas + 内联 SVG，零第三方库，零 CDN，零外部图片与字体。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；页面主体宽度不超过 680px 居中，375px 宽下链接按钮高度 ≥ 56px 便于单手点击。
2. 数据用 localStorage 持久化，key 前缀 "bio-"，提供「导出 JSON / 导入 JSON」。
3. 处理：URL 必须以 http:// 或 https:// 开头否则不允许保存（防 javascript: 注入）、空标题校验、外链统一 target="_blank" rel="noopener noreferrer"。
4. 视觉：现代简洁、大圆角按钮（12-16px）、hover 轻微上浮与阴影加深、渐进入场动画、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 隐私提醒：页面上注明「点击统计仅记录在本机浏览器，不会上传」。
6. 代码行数控制在 550 行以内，QR 部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Personal Link Hub" web app.

[CONFIG]
Nickname: {{NICKNAME}}
One-line bio: {{BIO}}
Links to show: {{LINKS}}

[FEATURES]
1. Header: avatar (Canvas-compressed to a circular base64 image, selectable locally), nickname, one-line bio, optional verified badge drawn as inline SVG.
2. Link list: title, URL, icon (platform initial letter or a simple inline SVG shape — no icon library), drag to reorder, editable, deletable, and individually hideable.
3. Groups: create 2-3 groups (e.g. "My work", "Contact", "Social"), each with its own heading and links.
4. Click tracking: record per-link click counts in localStorage, visible only in edit mode.
5. QR code: generate a QR for this page URL. Prefer embedding a compact QR encoder (it MUST be scannable); if that proves impractical, fall back to a QR placeholder with a note telling users to bookmark or use the browser share sheet, and explain why in the UI.
6. Themes: four presets (minimal white, midnight, purple gradient, cream warm) switchable in one tap, plus a custom primary color picker.
7. Export a read-only HTML version with data inlined, ready to drop on any static host or send to friends.

[DEPENDENCIES]
Vanilla JS + Canvas + inline SVG. Zero libraries, zero CDN, no external images or fonts.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; content column centered and no wider than 680px; link buttons at least 56px tall at 375px for one-handed tapping.
2. localStorage with key prefix "bio-"; Export/Import JSON.
3. Reject URLs not starting with http:// or https:// (prevents javascript: injection), validate empty titles, and always open external links with target="_blank" rel="noopener noreferrer".
4. Modern clean UI: large 12-16px button radius, hover lift with deeper shadow, staggered entrance animation, prefers-color-scheme dark mode, respect prefers-reduced-motion.
5. Privacy note: "Click counts are stored only in this browser and never uploaded."
6. Keep under 550 lines; comment the QR section.
````

## 生成后自检清单

- [ ] 每个链接点击都能跳转且新标签打开
- [ ] javascript: 开头的 URL 无法保存
- [ ] 主题切换后对比度仍然够看
- [ ] 二维码能被手机扫出来
- [ ] 导出只读版能单独打开且不含编辑入口
