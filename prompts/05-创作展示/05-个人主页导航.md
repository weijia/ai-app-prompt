# 个人主页导航

> 头像 + 简介 + 多平台链接 + 二维码分享 · 难度：★☆☆ · 约 2 分钟

## 适用场景

做一个类似 Linktree 的个人聚合页，放简历、公众号、作品链接，二维码发出去。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{昵称}}` | 展示的名字 | 「阿哲」 |
| `{{一句话介绍}}` | 简介 | 「前端工程师 / 业余摄影师」 |
| `{{链接清单}}` | 要放的链接 | 「博客、GitHub、公众号、小红书、邮箱」 |

## 提示词（中文版）

````text
请生成一个「个人主页导航」单文件网页应用。

【配置】
昵称：{{昵称}}
一句话介绍：{{一句话介绍}}
需要展示的链接：{{链接清单}}

【功能要求】
1. 头部：头像（Canvas 压缩为圆形 base64，支持本地选择）、昵称、一句话介绍、可选认证小图标（内联 SVG）。
2. 链接列表：每个链接含标题、URL、图标（用平台首字母或内联 SVG 简易图形，禁止图标库）、可拖拽排序、可编辑删除、可开关显示。
3. 分组：支持创建 2-3 个分组（如「我的作品」「联系我」「社交」），每组一个标题 + 一组链接。
4. 点击统计：每次点击记录次数到 localStorage，编辑模式下可查看每个链接的点击数（展示视图隐藏统计）。
5. 二维码：生成当前个人主页 URL 的二维码。若不方便内联完整 QR 编码器，则退而求其次——用一个「二维码占位 + 提示用户使用浏览器分享/保存书签」的方案，并在页面上说明原因。优先尝试内联精简 QR 编码器（必须能被手机扫出）。
6. 主题：提供 4 套预设主题（纯白极简、暗夜、渐变紫、奶油暖色），一键切换；支持自定义主色。
7. 导出：导出只读版 HTML（数据内联、只读展示），便于部署到任意静态托管或直接发给朋友。

【依赖策略】
纯原生 JavaScript + Canvas + 内联 SVG，零第三方库，零 CDN，零外部图片与字体。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；页面主体宽度不超过 680px 居中，375px 宽下链接按钮高度 ≥ 56px 便于单手点击。
2. 数据用 localStorage 持久化，key 前缀 "bio-"，提供「导出 JSON / 导入 JSON」。
3. 处理：URL 必须以 http:// 或 https:// 开头否则不允许保存（防 javascript: 注入）、空标题校验、外链统一 target="_blank" rel="noopener noreferrer"。
4. 视觉：现代简洁、大圆角按钮（12-16px）、hover 轻微上浮与阴影加深、渐进入场动画、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 隐私提醒：页面上注明「点击统计仅记录在本机浏览器，不会上传」。
6. 代码总量建议控制在 550 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。QR 部分加中文注释。
````

## 生成后自检清单

- [ ] 每个链接点击都能跳转且新标签打开
- [ ] javascript: 开头的 URL 无法保存
- [ ] 主题切换后对比度仍然够看
- [ ] 二维码能被手机扫出来
- [ ] 导出只读版能单独打开且不含编辑入口

## 常用追问

1. 「加访问量统计和最近访问时间（本机）」
2. 「加自我介绍长文折叠区」
3. 「支持背景自定义：渐变/纯色/上传图片」
