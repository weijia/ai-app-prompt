# 个人简历网页

> 单页在线简历 + 编辑模式 + 打印成 PDF · 难度：★★☆ · 约 3 分钟

## 适用场景

想有个能发给 HR 的链接式简历，同时能一键导出 PDF。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{岗位方向}}` | 投什么岗位 | 「前端工程师」 |
| `{{风格}}` | 排版风格 | 「极简黑白 / 蓝色商务 / 渐变年轻」 |

## 提示词（中文版）

````text
请生成一个「个人简历网页」单文件网页应用。

【配置】
目标岗位方向：{{岗位方向}}
期望风格：{{风格}}

【功能要求】
1. 双模式：查看模式（美观排版）/ 编辑模式（表单填写），右上角切换按钮；编辑内容实时反映到查看模式。
2. 简历区块（可拖拽调整顺序、可显隐）：
   - 头部：姓名、职位头衔、一句话简介、头像（Canvas 压缩转 base64）、联系方式（电话/邮箱/城市/个人网站）
   - 求职意向：目标岗位、期望薪资、到岗时间
   - 工作经历：公司、职位、起止年月、工作描述（支持多条要点）、可折叠
   - 项目经历：项目名、角色、时间、描述要点、技术栈标签
   - 教育背景：学校、专业、学历、时间
   - 技能标签：名称 + 熟练度（1-5 级，用点状或条形展示）
   - 自定义区块：标题 + 自由内容（用于证书、作品链接等）
3. 内置示例数据一键填充，方便先看效果再改成自己的。
4. 时间线展示：经历区块左侧绘制竖线时间轴（CSS 实现），按时间倒序自动排序。
5. 打印优化（重要）：提供「导出 PDF / 打印」按钮调用 window.print()，并编写 @media print 样式——隐藏所有按钮与编辑区、@page 设置 A4 与 0 边距、避免内容跨页断裂（break-inside: avoid）、黑白友好的配色。
6. 分享：导出单个 HTML 文件（把当前数据快照内联进去，只读）；也可导出 JSON 备份。
7. 响应式：桌面双栏（左个人信息右经历），窄屏单栏。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN，零外部字体与图片引用。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下排版不溢出、联系方式可点击（tel:/mailto:）。
2. 数据用 localStorage 持久化，key 前缀 "resume-"，图片压缩到最大边 400px；提供「导出 JSON / 导入 JSON」。
3. 处理：必填项（姓名、联系方式）校验、日期格式（YYYY-MM 或 YYYY）校验、删除经历条目需确认。
4. 视觉：根据 {{风格}} 设定主色与字体层级，留白充足，行高 1.6，技能熟练度可视化，prefers-color-scheme 暗色模式（打印时强制浅色）。
5. 隐私提示：页面底部注明「数据仅保存在本机浏览器，导出的 HTML 会包含你填写的联系方式，请谨慎分享」。
6. 代码行数控制在 700 行以内，打印样式部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Online Resume" web app.

[CONFIG]
Target role: {{ROLE}}
Desired style: {{STYLE}}

[FEATURES]
1. Two modes: View (beautiful layout) / Edit (form entry), toggled top-right; edits reflect in View instantly.
2. Resume blocks (drag to reorder, show/hide each):
   - Header: name, title, one-line summary, photo (Canvas-compressed to base64), contacts (phone / email / city / website)
   - Objective: target role, expected salary, availability
   - Work experience: company, position, start/end (YYYY-MM), bullet descriptions, collapsible
   - Projects: name, role, dates, bullet points, tech stack tags
   - Education: school, major, degree, dates
   - Skills: name + proficiency 1-5 rendered as dots or bars
   - Custom block: free title + content for certificates, portfolio links, etc.
3. One-click "fill with sample data" so users can preview before editing.
4. Timeline: draw a CSS vertical timeline for experience blocks, auto-sorted newest first.
5. Print quality (important): an "Export PDF / Print" button calling window.print() plus @media print styles — hide buttons and editing UI, @page A4 with no margins, avoid content breaking across pages (break-inside: avoid), monochrome-friendly palette.
6. Sharing: export a read-only single HTML snapshot with data inlined, plus JSON backup export.
7. Responsive: two columns on desktop (info left, experience right), single column on narrow screens.

[DEPENDENCIES]
Vanilla JS only. Zero libraries, zero CDN, no external fonts or images.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; no overflow at 375px, contacts clickable via tel:/mailto:.
2. localStorage with key prefix "resume-"; photo compressed to max 400px; Export/Import JSON.
3. Validate required fields (name, contact), date formats (YYYY-MM or YYYY), and confirm before deleting entries.
4. Visuals follow {{STYLE}}: consistent primary color and type hierarchy, generous whitespace, line-height 1.6, visible skill proficiency, prefers-color-scheme dark mode (force light when printing).
5. Footer privacy note: "Data is stored only in this browser; the exported HTML contains the contact details you entered — share carefully."
6. Keep under 700 lines; comment the print styles.
````

## 生成后自检清单

- [ ] 编辑模式改动立刻反映到查看模式
- [ ] 打印预览是 A4 且没有按钮和表单框
- [ ] 经历条目不会被跨页截断
- [ ] 导出的只读 HTML 能单独打开并正确显示照片
- [ ] 手机上 tel: 和 mailto: 能点击
