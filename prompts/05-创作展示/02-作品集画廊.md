# 作品集画廊

> 瀑布流 + 灯箱预览 + 标签筛选 · 难度：★★☆ · 约 3 分钟

## 适用场景

摄影、插画、设计稿的本地作品展示页，可导出分享。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{作品类型}}` | 展示什么 | 「手机摄影作品」 |
| `{{展示信息}}` | 每张图要显示什么 | 「标题、拍摄时间、器材参数」 |

## 提示词（中文版）

````text
请生成一个「作品集画廊」单文件网页应用。

【配置】
作品类型：{{作品类型}}
每张作品要展示的信息：{{展示信息}}

【功能要求】
1. 作品录入：标题、描述、标签（多选）、日期、图片（本地选择或拖拽，Canvas 等比压缩到最大边 1200px 后转 base64 存储）。
2. 瀑布流布局：用 CSS columns 或 CSS Grid + JS 计算实现响应式瀑布流；列数随视口宽度变化（375px 为 1-2 列，桌面 3-4 列），图片加载前用占位渐变避免跳动。
3. 灯箱预览：点击图片进入全屏遮罩，支持左右切换（箭头按钮 + 键盘 ←→ + 触屏左右滑动）、ESC 关闭、显示标题与描述、点击空白区关闭；切换时使用淡入淡出，不要生硬。
4. 筛选与搜索：标签多选筛选（支持「同时满足」/「任一满足」切换）、关键词搜索、按日期正倒序。
5. 懒加载：使用 IntersectionObserver 配合 data-src 做图片懒加载，避免一次渲染上百张图卡死。
6. 容量管理：页面顶部显示已用存储百分比（按 5MB 估算），超过 80% 时给出清理建议与导出按钮；单张压缩后仍超过 500KB 时提示。
7. 导出分享：导出 JSON 备份；导出「只读展示版 HTML」（数据内联，只读不能编辑），便于发给别人看。

【依赖策略】
纯原生 JavaScript + Canvas + IntersectionObserver，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用，灯箱支持手势滑动切换，按钮最小 44px。
2. 数据用 localStorage 持久化，key 前缀 "gallery-"；写入前 try/catch 捕获 QuotaExceededError 并给出明确提示（不要静默失败）。
3. 处理：非图片文件的拒绝提示、删除作品的二次确认、空画廊引导、图片损坏时的占位图。
4. 视觉：以作品为主体——页面背景尽量中性（浅色白 / 暗色深灰），图片圆角小阴影，hover 轻微上浮，prefers-color-scheme 暗色模式，尊重 prefers-reduced-motion。
5. 代码总量建议控制在 700 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。瀑布流计算与压缩部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Portfolio Gallery" web app.

[CONFIG]
Artwork type: {{TYPE}}
Info shown per piece: {{INFO}}

[FEATURES]
1. Add artwork: title, description, tags (multi-select), date, image (pick or drop locally, Canvas-downscaled to max 1200px longest side then stored as base64).
2. Masonry layout via CSS columns or CSS Grid with JS measurement; columns adapt to viewport (1-2 at 375px, 3-4 on desktop); gradient placeholders prevent layout shift before images decode.
3. Lightbox: tap an image for a fullscreen overlay with prev/next (arrow buttons + arrow keys + swipe), Esc to close, title and description visible, click-outside to close, soft crossfade transitions.
4. Filter & search: multi-tag filtering with an ANY/ALL mode toggle, keyword search, date sort both directions.
5. Lazy loading with IntersectionObserver and data-src so hundreds of images don't freeze the page.
6. Storage management: show used-percentage of the ~5MB quota at the top, suggest cleanup and export above 80%, warn if a single image still exceeds 500KB after compression.
7. Export/share: JSON backup plus a read-only "display version" HTML with data inlined for sending to others.

[DEPENDENCIES]
Vanilla JS + Canvas + IntersectionObserver. Zero libraries, zero CDN.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta, usable at 375px, swipeable lightbox, 44px minimum tap targets.
2. localStorage with key prefix "gallery-"; wrap writes in try/catch and surface QuotaExceededError clearly — never fail silently.
3. Reject non-image files, confirm before deleting, guide an empty gallery, show a placeholder for broken images.
4. Artwork-first visuals: neutral page background (white / dark gray), small rounded image shadow, subtle hover lift, prefers-color-scheme dark mode, respect prefers-reduced-motion.
5. Aim for about 700 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment masonry math and compression.
````

## 生成后自检清单

- [ ] 一次导入十几张图不卡死
- [ ] 灯箱能左右切换且 ESC 能关
- [ ] 标签筛选「同时满足」逻辑正确
- [ ] 存储快满时有明确提示而不是静默失败
- [ ] 导出的只读版能发给别人打开
