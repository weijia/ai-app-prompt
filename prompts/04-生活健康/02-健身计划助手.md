# 健身计划助手

> 训练模板 + 组次记录 + 容量趋势 · 难度：★★★ · 约 4 分钟

## 适用场景

健身房力量训练记录：今天练什么、上次举多重、这周容量涨没涨。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{训练目标}}` | 增肌/减脂/力量 | 「增肌」 |
| `{{器械条件}}` | 在家还是健身房 | 「健身房，自由重量为主」 |

## 提示词（中文版）

````text
请生成一个「健身计划助手」单文件网页应用。

【配置】
训练目标：{{训练目标}}
器械条件：{{器械条件}}

【功能要求】
1. 动作库：内置常见动作约 30 条（含所属肌群：胸/背/腿/肩/手臂/核心/有氧，名称 + 默认器械类型），用户可自行增删改；动作支持标记为「有氧」（按时间与距离记录）或「力量」（按重量与次数记录）。
2. 训练计划模板：创建多个模板（如「推日」「拉日」「腿日」），每个模板包含若干动作及目标组数/次数（如 4 组 x 8-12 次）。
3. 今日训练：选择模板开始一次训练；每个动作展开后可逐组录入重量(kg)与次数，自动带出「上次该动作的重量与次数」做参考；支持添加附加组、删除组、休息计时器（60 秒倒计时，Web Audio 提示音本地合成）。
4. 自动计算：每组容量 = 重量 x 次数，动作总容量与本次训练总容量；1RM 估算（Epley 公式：1RM = weight * (1 + reps/30)）并显示。
5. 训练历史：按日期倒序列出每次训练（总时长、总容量、动作数），可点开查看详情、继续上次模板、删除记录。
6. 趋势图：选定某个动作后可看其最近 12 次训练的「最大重量」与「总容量」折线趋势（内联 SVG polyline 手绘，零依赖）。
7. 数据统计：本周训练次数、各肌群训练容量占比（纯 CSS 横向条形），连续训练周数。

【依赖策略】
纯原生 JavaScript + 内联 SVG + Web Audio，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下组次录入使用大号数字输入 + 步进按钮，键盘弹出时不遮挡提交按钮（输入框使用 inputmode="decimal"）。
2. 数据用 localStorage 持久化，key 前缀 "gym-"，提供「导出 JSON / 导入 JSON」。
3. 处理：重量为 0 或负数的校验、未完成训练中途退出的保存草稿、删除历史记录的二次确认。
4. 视觉：现代简洁、肌群用不同色标区分、组次完成时有轻微动效、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 附加：所有计算在本地完成，页面上声明「数据仅保存在本机浏览器，请自行导出备份」。
6. 代码行数控制在 750 行以内，容量与 1RM 计算部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Workout Planner" web app.

[CONFIG]
Goal: {{GOAL}}
Equipment: {{EQUIPMENT}}

[FEATURES]
1. Exercise library: about 30 built-in common lifts tagged by muscle group (chest / back / legs / shoulders / arms / core / cardio) with a default equipment type; users can add, edit and remove. Each exercise is either cardio (time + distance) or strength (weight + reps).
2. Plan templates: create templates such as "Push day", "Pull day", "Leg day", each listing exercises with target sets and reps (e.g. 4 sets x 8-12 reps).
3. Today's session: pick a template to start; expanding an exercise lets you log weight (kg) and reps set by set, while showing the previous session's numbers for reference; support extra sets, deleting sets, and a 60s rest timer with a Web Audio synth beep (no external audio).
4. Auto calculations: set volume = weight x reps, per-exercise and session totals; estimate 1RM with the Epley formula 1RM = weight * (1 + reps/30) and display it.
5. History: sessions listed newest first (duration, total volume, exercise count); open for detail, restart the same template, or delete.
6. Trend charts: pick an exercise to see its last 12 sessions of top weight and total volume as a line chart drawn by hand with inline SVG polyline — zero deps.
7. Stats: sessions this week, volume share per muscle group (pure CSS horizontal bars), consecutive training weeks.

[DEPENDENCIES]
Vanilla JS + inline SVG + Web Audio. Zero libraries, zero CDN.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px use big numeric inputs with steppers and inputmode="decimal" so the on-screen keyboard never covers the confirm button.
2. localStorage with key prefix "gym-"; Export/Import JSON.
3. Validate zero/negative weights, keep a draft when leaving a session unfinished, and confirm before deleting history.
4. Modern clean UI: muscle-group color coding, subtle animation on completed sets, prefers-color-scheme dark mode, respect prefers-reduced-motion.
5. All computation stays local and the page states "Data is stored only in this browser — export your own backup."
6. Keep under 750 lines; comment the volume and 1RM math.
````

## 生成后自检清单

- [ ] 开始训练能带出上次该动作的重量
- [ ] 组容量和总容量计算正确
- [ ] 休息计时器结束后有提示音
- [ ] 趋势图选不同动作会切换数据
- [ ] 手机输入重量时键盘不遮住确认键
