# 旅行行程规划器

> 多日行程 + 预算表 + 地图链接 + 可打印 · 难度：★★★ · 约 4 分钟

## 适用场景

出门前排行程：每天去哪、花多少钱、怎么走，最后打印一份带着走。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{目的地}}` | 去哪 | 「日本关西 7 天」 |
| `{{关注重点}}` | 更看重什么 | 「预算控制 + 交通衔接」 |

## 提示词（中文版）

````text
请生成一个「旅行行程规划器」单文件网页应用。

【配置】
目的地与天数：{{目的地}}
我最关注的：{{关注重点}}

【功能要求】
1. 行程结构：左侧按天列表（Day 1 / Day 2…，显示日期与当天安排数），右侧是选中那天的时段卡片。
2. 每日安排条目：时间（HH:mm，可选）、地点名称、类别（交通/住宿/餐饮/景点/购物/其他，用不同色标）、停留时长、预计花费、货币、备注、地图链接（用户粘贴高德/Google Maps 链接，页面渲染为「打开地图」按钮，target="_blank" rel="noopener"）。
3. 时间轴视图：当天条目按时间排序后在左侧画一条竖线时间轴（CSS 实现），未填时间的条目排在最后并标注「时间待定」。
4. 预算管理：总预算输入，自动汇总已录入花费并按类别统计占比（纯 CSS 横向条形）；超预算时总览卡片变红并显示超出金额；支持多货币时统一折算为人民币（汇率由用户手动填写表单，不做网络请求）。
5. 拖拽与排序：条目支持拖拽调整当天的顺序（HTML5 drag + pointer 触屏兼容），也可手动点「上移/下移」。
6.  checklist：内置一个可勾选的行前准备清单（证件/充电/药品/转换插头等，条目可自行增删），并按用途分组展示。
7. 打印与分享：提供打印按钮（window.print() + @media print 样式，隐藏所有按钮、展开所有天数、黑白友好）；提供「导出 JSON」与「导出 Markdown 文本行程」。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN，不做任何网络请求，不调用任何地图或汇率 API。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；375px 宽下左侧天数列表改为顶部横向滚动的日期胶囊，右侧卡片单列全宽。
2. 数据用 localStorage 持久化，key 前缀 "trip-"，提供「导出 JSON / 导入 JSON」。
3. 处理：日期范围非法（结束早于开始）的校验、花费为负数的提示、删除某一天时的二次确认（提示当天所有条目都会被删）、空行程引导。
4. 视觉：现代简洁、类旅行主题的蓝/青主色、类别色标清晰、prefers-color-scheme 暗色模式。
5. 代码行数控制在 750 行以内，预算换算与排序部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Trip Itinerary Planner" web app.

[CONFIG]
Destination & duration: {{DESTINATION}}
What I care about most: {{PRIORITY}}

[FEATURES]
1. Structure: left column lists days (Day 1 / Day 2... with date and item count), right pane shows that day's timed cards.
2. Itinerary item: time (HH:mm, optional), place name, category (transport / lodging / food / attraction / shopping / other, each with its own color), duration, estimated cost, currency, notes, and a map link (user pastes an Amap/Google Maps URL; render it as an "Open map" button with target="_blank" rel="noopener").
3. Timeline view: sort the day's items by time and draw a CSS vertical timeline on the left; items without a time go last, labeled "time TBD".
4. Budget: set a total budget; sum entered costs and show per-category share (pure CSS horizontal bars); when over budget the summary card turns red and shows the overage; for multi-currency trips convert to CNY using a user-entered exchange rate form — no network requests.
5. Reordering: drag items within a day (HTML5 drag plus pointer-based touch support) or use explicit move up/down buttons.
6. Checklist: a built-in pre-trip checklist (documents / chargers / medicine / plug adapter, editable and extensible) grouped by purpose.
7. Print & share: print via window.print() with @media print styles (hide all buttons, expand every day, print-friendly monochrome), export JSON, and export a Markdown itinerary.

[DEPENDENCIES]
Vanilla JS only. Zero libraries, zero CDN, no network requests, no map or exchange-rate APIs.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px the day list becomes a horizontally scrolling row of date pills and items go full width in one column.
2. localStorage with key prefix "trip-"; Export/Import JSON.
3. Validate date ranges, reject negative costs, confirm before deleting a day (stating all its items go too), and guide empty itineraries.
4. Modern clean UI with a travel-themed blue/teal primary, clear category colors, prefers-color-scheme dark mode.
5. Keep under 750 lines; comment the budget conversion and sorting logic.
````
