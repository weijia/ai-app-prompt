# 旅行行程规划器

> 多日行程 + 预算表 + 地图链接 + 可打印 · 难度：★★★ · 约 4 分钟

## 适用场景

出门前排行程：每天去哪、花多少钱、怎么走，最后打印一份带着走。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{目的地}}` | 去哪 | 「日本关西 7 天」 |
| `{{关注重点}}` | 更看重什么 | 「预算控制 + 交通衔接」 |

## 提示词（中文版）

````text
请生成一个「旅行行程规划器」单文件网页应用。

【配置】
目的地与天数：{{目的地}}
我最关注的：{{关注重点}}

【功能要求】
1. 行程结构：左侧按天列表（Day 1 / Day 2…，显示日期与当天安排数），右侧是选中那天的时段卡片。
2. 每日安排条目：时间（HH:mm，可选）、地点名称、类别（交通/住宿/餐饮/景点/购物/其他，用不同色标）、停留时长、预计花费、货币、备注、地图链接（用户粘贴高德/Google Maps 链接，页面渲染为「打开地图」按钮，target="_blank" rel="noopener"）。
3. 时间轴视图：当天条目按时间排序后在左侧画一条竖线时间轴（CSS 实现），未填时间的条目排在最后并标注「时间待定」。
4. 预算管理：总预算输入，自动汇总已录入花费并按类别统计占比（纯 CSS 横向条形）；超预算时总览卡片变红并显示超出金额；支持多货币时统一折算为人民币（汇率由用户手动填写表单，不做网络请求）。
5. 拖拽与排序：条目支持拖拽调整当天的顺序（HTML5 drag + pointer 触屏兼容），也可手动点「上移/下移」。
6.  checklist：内置一个可勾选的行前准备清单（证件/充电/药品/转换插头等，条目可自行增删），并按用途分组展示。
7. 打印与分享：提供打印按钮（window.print() + @media print 样式，隐藏所有按钮、展开所有天数、黑白友好）；提供「导出 JSON」与「导出 Markdown 文本行程」。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN，不做任何网络请求，不调用任何地图或汇率 API。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；375px 宽下左侧天数列表改为顶部横向滚动的日期胶囊，右侧卡片单列全宽。
2. 数据用 localStorage 持久化，key 前缀 "trip-"，提供「导出 JSON / 导入 JSON」。
3. 处理：日期范围非法（结束早于开始）的校验、花费为负数的提示、删除某一天时的二次确认（提示当天所有条目都会被删）、空行程引导。
4. 视觉：现代简洁、类旅行主题的蓝/青主色、类别色标清晰、prefers-color-scheme 暗色模式。
5. 代码总量建议控制在 750 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。预算换算与排序部分加中文注释。
````

## 生成后自检清单

- [ ] 增加天数后左侧日期自动带日历日期
- [ ] 花费汇总数字与实际录入一致
- [ ] 多货币填入汇率后折算准确
- [ ] 打印预览隐藏了按钮且所有天数展开
- [ ] 刷新后行程完整保留

## 常用追问

1. 「加地图坐标：粘贴经纬度后渲染成静态缩略图」（提醒：不允许引地图 SDK）
2. 「加预算分摊：多人同行 AA 计算」
3. 「导出成每日一卡的手机壁纸」（用 canvas 生成）
