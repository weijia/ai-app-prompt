# 习惯打卡追踪

> 多习惯日历热力图 + 连续天数激励 + 月度完成率 · 难度：★★☆ · 约 3 分钟

## 适用场景

早起、喝水、运动、阅读等日常习惯的坚持记录，靠可视化督促自己。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{习惯清单}}` | 想追踪的习惯 | 「早起、喝水 2L、运动 30 分钟、读书」 |
| `{{激励方式}}` | 喜欢什么反馈 | 「连续天数 + 徽章解锁」 |

## 提示词（中文版）

````text
请生成一个「习惯打卡追踪」单文件网页应用。

【配置】
我想追踪的习惯：{{习惯清单}}
希望看到的激励方式：{{激励方式}}

【功能要求】
1. 今日打卡区：每个习惯一张可点击的卡片，点击即完成/取消完成；已完成时卡片变主色并显示对勾徽标。
2. 日历热力图：为每个习惯渲染最近 12 周（或当年整年）的日历格子，颜色按当天是否完成分级（未完成浅灰、完成用主色，若习惯有数值目标则按达成比例分 4 级深浅）；支持 hover/长按显示当天日期与状态。用 CSS Grid 布局，零依赖。
3. 数值型习惯支持：部分习惯录入每日数值（如喝水 2000ml、跑步 5km），可在习惯设置里切换「是否记录数值」并设定目标值；输入后热度按百分比计算。
4. 连续统计：当前连续天数、最长历史连续天数、本月完成率；破纪录时显示一个庆祝动画（纯 CSS 彩纸或缩放动画，不外链资源）。
5. 徽章系统（规则写在代码里）：连续 3/7/21/66/100 天解锁对应徽章，达成时弹出提示；徽章墙展示已解锁与未解锁（灰色）。
6. 备注功能：每天可以给某个习惯写一句备注（如「今天下雨改成室内运动」），在热力图点击日期后可编辑。
7. 月份切换与年度总览切换。

【依赖策略】
纯原生 JavaScript + CSS Grid，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【日期正确性要求】
所有日期使用本地时区的 YYYY-MM-DD 字符串作为 key（不要用 Date 的 UTC 方法拼接，否则会差一天）；跨天判断以本地零点为准；页面上显示的连续天数必须在跨月、跨年时依然正确。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下热力图改为横向滚动并固定首行星期标签，打卡按钮最小 44px 高。
2. 数据用 localStorage 持久化，key 前缀 "habit-"，提供「导出 JSON / 导入 JSON」。
3. 处理：新增/删除习惯时历史记录的处理（删除需二次确认并说明会清除该习惯记录）、目标值为 0 或负数的校验。
4. 视觉：现代简洁、圆角卡片、热力图配色克制（建议深浅蓝或深浅绿）、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 代码总量建议控制在 700 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。日期处理与连续天数计算部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Habit Tracker" web app.

[CONFIG]
Habits to track: {{HABITS}}
Motivation style: {{MOTIVATION}}

[FEATURES]
1. Today section: one tappable card per habit; tapping toggles completion, completed cards turn the primary color with a check badge.
2. Calendar heatmap per habit covering the last 12 weeks (or the full current year), color-coded by status (light gray when missed, primary color when done; for numeric habits use 4 shades based on goal completion). Hover or long-press shows the date and status. Built with CSS Grid — zero deps.
3. Numeric habit support: toggle "record a value" per habit with a target (e.g. 2000ml water, 5km run); entered values drive the heat level by percentage.
4. Streaks: current streak, longest-ever streak, completion rate this month, and a celebration animation when a record breaks (pure CSS confetti or scale animation, no external assets).
5. Badge system with rules in code: unlock at 3 / 7 / 21 / 66 / 100 consecutive days with a popup on unlock; a badge wall shows unlocked and locked (gray) badges.
6. Daily notes per habit (e.g. "rained, switched to indoor workout"), editable after tapping a heatmap date.
7. Month switcher plus a full-year overview toggle.

[DEPENDENCIES]
Vanilla JS + CSS Grid. Zero libraries, zero CDN.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[DATE CORRECTNESS]
Key every record by a local-timezone YYYY-MM-DD string — do not compose it from UTC getters, or dates shift by one. Day boundaries use local midnight. Streaks must stay correct across month and year changes.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px the heatmap scrolls horizontally with a sticky weekday header row and check buttons are at least 44px tall.
2. localStorage with key prefix "habit-"; Export/Import JSON.
3. Handle adding/removing habits (delete needs confirmation and must state it clears that habit's history) and validate targets that are zero or negative.
4. Modern clean UI: rounded cards, restrained heat palette (light-to-dark blue or green), prefers-color-scheme dark mode, respect prefers-reduced-motion.
5. Aim for about 700 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment date handling and streak math.
````

## 生成后自检清单

- [ ] 热力图日期和真实日历对得上（不差一天）
- [ ] 连续天数跨月后仍然正确
- [ ] 取消打卡后连击数正确归零但不影响历史最长纪录
- [ ] 数值型习惯按百分比显示深浅
- [ ] 刷新页面后今日打卡状态还在
