# 菜谱收藏本

> 菜谱卡片 + 份量换算 + 一键生成购物清单 · 难度：★★☆ · 约 3 分钟

## 适用场景

把自己会做的菜存下来，做饭前按份量自动换算用量，缺什么直接导出清单。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{菜谱来源}}` | 一般怎么录 | 「手打录入 + 粘贴网页文本」 |
| `{{常用标签}}` | 分类方式 | 「快手菜、家常菜、汤羹、主食」 |

## 提示词（中文版）

````text
请生成一个「菜谱收藏本」单文件网页应用。

【配置】
菜谱来源方式：{{菜谱来源}}
常用标签：{{常用标签}}

【功能要求】
1. 菜谱字段：菜名、封面图（可选，本地压缩转 base64）、标签（多选）、份数、耗时、难度、食材清单（每项含名称、用量、单位、可选备注）、步骤（多步，序号自动排列）、小贴士。
2. 份量换算：顶部提供「份数」输入框，改动时食材用量按比例实时重算；换算结果做合理取整（例如 1/3 勺显示为 0.33，大数值保留一位小数）。
3. 烹饪模式：进入后步骤大字号全屏显示，支持点击勾选已完成步骤、上/下一步、屏幕常亮提示（若浏览器支持 Wake Lock API 则尝试申请，不支持时忽略），防止手机熄屏。
4. 购物清单：勾选若干菜谱后可生成合并购物清单，相同食材单位一致时自动累加数量，单位不同则分行显示；清单支持勾选删除并可导出为文本 / 打印（window.print() + @media print 样式）。
5. 列表与搜索：卡片网格展示（封面图占位图案使用 CSS 渐变或 emoji，不引外部图片），支持按标签筛选、按菜名/食材搜索、按收藏置顶。
6. 今日推荐：随机推荐一个菜谱卡片，附带「换一个」按钮（使用 crypto 或 Math.random 均可，本场景不涉安全）。

【依赖策略】
纯原生 JavaScript + Canvas 图片压缩 + Blob 导出，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽卡片两列网格；注意 localStorage 约 5MB 上限，图片一律压缩到最大边 600px 且 JPEG 质量 0.7，写入前检测容量并在接近上限时提示导出备份。
2. 数据用 localStorage 持久化，key 前缀 "recipe-"，提供「导出 JSON / 导入 JSON」。
3. 处理：必填项校验、食材数量非法时的提示、空清单引导、图片过大提示。
4. 视觉：现代简洁、暖色调主色（食欲感）、卡片封面渐变兜底、prefers-color-scheme 暗色模式。
5. 代码行数控制在 650 行以内，份量换算与购物清单合并逻辑加中文注释。
````

````text
Generate a single-file "Recipe Collection" web app.

[CONFIG]
How recipes are added: {{SOURCE}}
Common tags: {{TAGS}}

[FEATURES]

3. Cook mode: fullscreen large-type steps with check-off completion, prev/next navigation, and a best-effort screen wake lock via the Wake Lock API (ignore silently if unsupported) so the phone doesn't dim mid-recipe.
4. Shopping list: select several recipes to merge into one list; same ingredient and unit get summed, different units stay on separate lines; items can be checked off, exported as text, or printed via window.print() with @media print styles.

Vanilla JS + Canvas compression + Blob export. Zero libraries, zero CDN.

One complete index.html, all inline. No npm, no build tools.

## 生成后自检清单

- [ ] 改份数后所有食材用量同步变化
- [ ] 购物清单能把多个菜谱的同名食材累加
- [ ] 烹饪模式步骤能勾选且不会被熄屏打断（支持的浏览器）
- [ ] 图片被压缩后仍能正常显示
- [ ] 打印预览里购物清单排版正常
