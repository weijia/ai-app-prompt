# 速算训练器

> 限时口算练习 + 错题回顾 + 成绩曲线 · 难度：★★☆ · 约 3 分钟

## 适用场景

给小学生做口算练习，或成年人练心算速度。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{学段}}` | 难度定位 | 「小学二年级」 |
| `{{题型}}` | 练习哪一种运算 | 「100 以内加减法、乘法口诀」 |
| `{{每题限时}}` | 每题几秒 | 「10」 |

## 提示词（中文版）

````text
请生成一个「速算训练器」单文件网页应用。

【配置】
适用学段：{{学段}}
题型范围：{{题型}}
每题限时：{{每题限时}} 秒（超时自动判错并进入下一题）

【功能要求】
1. 首页设置：选择题型（加减乘除可多选）、数值范围（如 10 以内 / 100 以内 / 乘法口诀）、题目数量（10/20/50）、是否限时。
2. 练习界面：超大号题目居中，数字键盘（0-9、删除、确定）供手机点击；同时支持物理键盘直接输入数字、回车提交、退格删除。输入即时回显。
3. 判定与反馈：答对显示绿色对勾 + 短促上升音效（Web Audio 合成，不外链音频），答错显示正确答案与红色叉 + 下降音效；答错自动在 1.2 秒后进入下一题。
4. 出题逻辑：
   - 减法结果不得为负数（学段较小时）
   - 除法必须整除
   - 相邻两题不得完全相同
   - 乘法两个因数都在所选范围内
5. 结算页：总题数、正确数、正确率、用时、平均每题秒数；列出所有错题（题干、你的答案、正确答案）供复习。
6. 错题本：错题自动累积，可在首页选择「只练错题」模式；错题重做答对后移除。
7. 成绩曲线：最近 10 次练习的正确率折线图，用内联 SVG 手绘 polyline 实现（零依赖），不引第三方图表库。
8. 计时器同样要求基于 Date.now() 时间戳计算，避免后台标签页降频导致计时不准。

【依赖策略】
纯原生 JavaScript + 内联 SVG + Web Audio API，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下数字键盘高度合理、不遮挡题目；按钮最小 44x44px。
2. 数据用 localStorage 持久化，key 前缀 "mathdrill-"（保存历史成绩与错题本），提供「导出 JSON / 导入 JSON」。
3. 处理：答案为空时不允许提交、练习中途退出需确认、练习完成前禁止切到结算页。
4. 视觉：大字号、高对比、明快活泼的配色（适龄感），答对答错有明显动效，prefers-color-scheme 暗色模式，尊重 prefers-reduced-motion。
5. 代码行数控制在 650 行以内，出题规则部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Mental Math Drill" web app.

[CONFIG]
Grade level: {{GRADE}}
Operations: {{OPS}}
Per-question limit: {{LIMIT}} seconds (timeout counts as wrong and auto-advances)

[FEATURES]
1. Home setup: pick operations (add / subtract / multiply / divide, multi-select), numeric range (within 10 / 100 / times tables), question count (10/20/50), and whether to enforce a time limit.
2. Practice screen: oversized question centered, on-screen numeric keypad (0-9, backspace, confirm) for touch, plus physical keyboard support — digits to type, Enter to submit, Backspace to delete. Show input live.
3. Feedback: green check + short rising tone on correct (Web Audio synth, no external audio files), red cross with the correct answer + falling tone on wrong; auto-advance 1.2s after a wrong answer.
4. Question generation rules:
   - no negative results for subtraction at low grade levels
   - division must divide evenly
   - no duplicate adjacent questions
   - both multiplicands within the selected range
5. Results screen: total, correct, accuracy, elapsed time, average seconds per question, plus a list of mistakes (question, your answer, correct answer).
6. Mistake bank: accumulate wrong answers, offer a "mistakes only" mode from the home screen, and remove an item once answered correctly.
7. Progress curve: accuracy line chart of the last 10 sessions drawn by hand with inline SVG polyline — no chart library.
8. Compute timing from Date.now() timestamps so background-tab throttling can't distort it.

[DEPENDENCIES]
Vanilla JS + inline SVG + Web Audio API. Zero libraries, zero CDN.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px the keypad must not cover the question and every key is at least 44x44px.
2. localStorage with key prefix "mathdrill-" (history + mistake bank); Export/Import JSON.
3. Block submit on empty answer, confirm before quitting mid-session, no result screen before finishing.
4. Large high-contrast type, playful age-appropriate palette, clear right/wrong animations, prefers-color-scheme dark mode, respect prefers-reduced-motion.
5. Keep under 650 lines; comment the generation rules.
````

## 生成后自检清单

- [ ] 减法不会出现负结果
- [ ] 除法都能整除
- [ ] 物理键盘能直接输数字作答
- [ ] 超时后进下一题而不是卡住
- [ ] 错题本会积累，重做答对后消失
