# 学习计划甘特图

> 任务排期可视化 + 依赖关系 + 进度追踪 · 难度：★★★ · 约 4 分钟

## 适用场景

备考计划、课程排期、项目学习路径，看清哪天该干什么、有没有排太满。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{计划主题}}` | 排什么计划 | 「考研三个月复习计划」 |
| `{{时间粒度}}` | 按天还是按周 | 「按周，共 12 周」 |

## 提示词（中文版）

````text
请生成一个「学习计划甘特图」单文件网页应用。

【配置】
计划主题：{{计划主题}}
时间粒度：{{时间粒度}}

【功能要求】
1. 任务管理：任务名、开始日期、结束日期、负责人（可留空）、进度百分比、颜色标签、所属阶段/模块、前置任务（可多选）。
2. 甘特图主体：
   - 左侧固定任务列表（任务名 + 进度百分比），右侧按时间轴绘制横向条
   - 用 CSS Grid 或绝对定位绘制，日期→像素的换算写成一个函数，方便切换粒度
   - 显示「今天」基准竖线（红色虚线）
   - 鼠标悬停任务条显示 tooltip（起止日期、工期、进度）
   - 任务条内的进度用深色内条表示
3. 依赖箭头：前置任务的结束位置到当前任务开始位置画一条折线（内联 SVG path 实现，注意处理任务在同行的情况）。
4. 冲突检测：若某个任务的前置任务结束日期晚于自身开始日期，用红色边框高亮该任务并在顶部显示一个警告数量徽章。
5. 视图控制：日/周/月三种粒度切换、横向滚动、缩放（横向条长度倍率）。
6. 拖拽调整：拖动任务条整体平移改期（鼠标 + 触屏 pointer 事件均可），拖左右边缘改开始/结束日期；拖动结束后自动校验依赖冲突。
7. 统计：总任务数、已完成数、进行中数、延期未完成数、整体完成百分比环形图（纯 CSS conic-gradient）。

【依赖策略】
纯原生 JavaScript + 内联 SVG + CSS Grid + pointer events。零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；375px 宽下左侧任务列收窄至 120px，时间轴横向滚动，并提供「双指/按钮缩放」；拖拽在小屏上可切换为「点选任务后在弹窗里改日期」的替代方案。
2. 数据用 localStorage 持久化，key 前缀 "gantt-"，提供「导出 JSON / 导入 JSON」。
3. 处理：结束日期早于开始日期的校验提示、空任务列表引导、依赖成环的检测（禁止保存并提示）。
4. 视觉：现代简洁、任务条圆角、周末列底色浅灰、今天竖线醒目、prefers-color-scheme 暗色模式。
5. 代码行数控制在 750 行以内，日期换算与依赖校验部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Study Plan Gantt" web app.

[CONFIG]
Plan topic: {{TOPIC}}
Granularity: {{GRANULARITY}}

[FEATURES]
1. Task model: name, start date, end date, owner (optional), progress %, color label, phase/module, predecessor tasks (multi-select).
2. Gantt body:
   - left column is a pinned task list (name + progress %), right side draws horizontal bars along the timeline
   - build it with CSS Grid or absolute positioning and isolate the date-to-pixel conversion in one function so granularity can switch cleanly
   - red dashed vertical marker for today
   - hover a bar to show a tooltip (start, end, duration, progress)
   - progress rendered as a darker inner bar
3. Dependency arrows: draw a polyline from the predecessor's end position to the task's start position using inline SVG paths (handle the same-row case).
4. Conflict detection: when a predecessor ends later than this task starts, outline the task in red and show a warning count badge up top.
5. View controls: day / week / month granularity, horizontal scrolling, zoom (bar length multiplier).
6. Drag to reschedule: move a whole bar or resize either edge with mouse and pointer/touch events; re-validate dependencies after each drag.
7. Stats: total / completed / in progress / overdue tasks plus an overall completion ring drawn with pure CSS conic-gradient.

[DEPENDENCIES]
Vanilla JS + inline SVG + CSS Grid + pointer events. Zero libraries, zero CDN.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px shrink the left column to 120px, scroll the timeline horizontally, offer pinch/button zoom, and provide a tap-to-open date picker dialog as the small-screen alternative to dragging.
2. localStorage with key prefix "gantt-"; Export/Import JSON.
3. Validate end-before-start, guide empty plans, and detect circular dependencies (block saving with a message).
4. Modern clean UI: rounded bars, light gray weekend columns, prominent today marker, prefers-color-scheme dark mode.
5. Keep under 750 lines; comment the date mapping and dependency validation.
````
