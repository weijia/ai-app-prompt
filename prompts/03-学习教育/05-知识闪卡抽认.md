# 知识闪卡抽认

> 自定义问答卡组 + 顺序/随机 + 正确率统计 · 难度：★☆☆ · 约 2 分钟

## 适用场景

任何科目的自问自答：历史年代、法律条文、医学名词、面试题。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{知识领域}}` | 卡组内容 | 「前端八股文面试题」 |
| `{{卡片形式}}` | 正反面各写什么 | 「正面问题，背面要点」 |

## 提示词（中文版）

````text
请生成一个「知识闪卡抽认」单文件网页应用。

【配置】
知识领域：{{知识领域}}
卡片形式：{{卡片形式}}

【功能要求】
1. 卡组管理：多个卡组，卡片含正面（问题）与背面（答案要点，支持多行）；支持批量导入（每行一题，Tab 或 || 分隔正反面）、拖拽排序（HTML5 drag events + pointer 触屏兼容）、卡片删除。
2. 三种练习模式：
   - 顺序模式：按卡组原顺序推进
   - 随机模式：Fisher–Yates 洗牌后推进
   - 只练错卡：仅抽上次标记为「还没记住」的卡
3. 练习流程：先显示正面，用户心里作答后点击「显示答案」，然后自评「记住了 / 还没记住」；记录每张卡的连续答对次数与上次结果。
4. 键盘操作：空格翻面，← 表示没记住，→ 表示记住，Esc 退出练习。
5. 进度条：顶部显示当前第 n / 共 m 张，以及本轮答对率实时更新。
6. 统计面板：每个卡组的总卡数、已掌握（连续答对 ≥ 3 次）、学习中、未练过的数量；最近 5 轮答对率柱状图（纯 CSS div 高度实现）。
7. 导入导出：卡组 JSON 导入导出，并支持导出为可分享的纯阅读版 HTML（只读翻卡）。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下卡片高度自适应内容、底部大按钮单手可及。
2. 数据用 localStorage 持久化，key 前缀 "quizcard-"，提供「导出 JSON / 导入 JSON」。
3. 处理：空卡组不能开始练习并给出引导、导入格式错误的行跳过并汇总提示、练习到最后一张时给出「重新开始 / 只练错卡」选择。
4. 视觉：现代简洁、翻卡动画 300ms、答对绿色 / 未记住橙色反馈、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 代码总量建议控制在 600 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。洗牌与统计分析部分加中文注释。
````

## 生成后自检清单

- [ ] 批量导入多行被正确拆成卡片
- [ ] 随机模式每次顺序都不同
- [ ] 空卡组点开始会提示而非报错
- [ ] 「只练错卡」只会抽到上次不会的卡
- [ ] 导出的阅读版 HTML 能单独打开翻阅
