# 错题本

> 记录错在哪、为什么错，定期重测直到真会 · 难度：★★☆ · 约 3 分钟

## 适用场景

考试/作业错题整理，支持图片粘贴（本地存储）、标签分类、随机重测。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{学科}}` | 主要科目 | 「初中数学」 |
| `{{标签体系}}` | 想怎么归类 | 「章节 + 错误类型：计算错/概念错/审题错」 |

## 提示词（中文版）

````text
请生成一个「错题本」单文件网页应用。

【配置】
学科：{{学科}}
标签体系：{{标签体系}}

【功能要求】
1. 错题录入表单：题干（多行必填）、我的答案、正确答案、错误原因分析（必填，从预设原因里选，也可自定义）、涉及知识点/章节标签、难度星级 1-5、备注。
2. 图片支持：可粘贴、拖拽或选择本地图片；在前端用 Canvas 把图片等比缩放到最大边 800px 并转为 base64 存入 localStorage（必须做体积压缩，单张超过 300KB 时提示）。
3. 错题列表：卡片式展示，支持按学科章节、错误原因、难度筛选，按录入时间/复习次数排序，支持关键词搜索（搜索题干与答案）。
4. 掌握状态：每条错题有「未掌握 / 复习中 / 已掌握」三态，手动切换；列表可用状态筛选。
5. 重测模式：选择筛选条件后进入全屏重测，只看题目不显示答案，用户自评「会了 / 还不会」，系统更新掌握状态与复习次数，并在结束时给出统计。
6. 复习提醒：根据录入日期与复习次数计算「今日待复习」数量，首页用醒目卡片展示（间隔规则：第 1、3、7、15 天各复习一次）。
7. 导出：导出全部错题的 JSON；导出为打印友好的页面（window.print() + @media print 样式，每道题占一块、图片不跨页）。

【依赖策略】
纯原生 JavaScript + Canvas + fileReader + Blob。零第三方库，零 CDN，不做 OCR，图片内容靠用户自己填写题干。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下表单单列、列表卡片全宽。
2. 数据用 localStorage 持久化，key 前缀 "wrongbook-"；注意 localStorage 约 5MB 上限，写入前检测，接近上限时给出明确提示并建议导出备份。
3. 处理：必填项未填的校验、图片过大/过多的提示、空列表引导文案。
4. 视觉：现代简洁、学科标签用色块区分、难度星级可点选、prefers-color-scheme 暗色模式。
5. 代码总量建议控制在 650 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。图片压缩与复习间隔计算部分加中文注释。
````

## 生成后自检清单

- [ ] 粘贴的截图能被压缩后显示出来
- [ ] 刷新后图片还在
- [ ] 重测模式不显示答案
- [ ] 今日待复习数量符合 1/3/7/15 天规则
- [ ] 打印预览里题目不会被截断
