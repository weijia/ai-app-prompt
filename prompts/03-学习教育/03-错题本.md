# 错题本

> 记录错在哪、为什么错，定期重测直到真会 · 难度：★★☆ · 约 3 分钟

## 适用场景

考试/作业错题整理，支持图片粘贴（本地存储）、标签分类、随机重测。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{学科}}` | 主要科目 | 「初中数学」 |
| `{{标签体系}}` | 想怎么归类 | 「章节 + 错误类型：计算错/概念错/审题错」 |

## 提示词（中文版）

````text
请生成一个「错题本」单文件网页应用。

【配置】
学科：{{学科}}
标签体系：{{标签体系}}

【功能要求】
1. 错题录入表单：题干（多行必填）、我的答案、正确答案、错误原因分析（必填，从预设原因里选，也可自定义）、涉及知识点/章节标签、难度星级 1-5、备注。
2. 图片支持：可粘贴、拖拽或选择本地图片；在前端用 Canvas 把图片等比缩放到最大边 800px 并转为 base64 存入 localStorage（必须做体积压缩，单张超过 300KB 时提示）。
3. 错题列表：卡片式展示，支持按学科章节、错误原因、难度筛选，按录入时间/复习次数排序，支持关键词搜索（搜索题干与答案）。
4. 掌握状态：每条错题有「未掌握 / 复习中 / 已掌握」三态，手动切换；列表可用状态筛选。
5. 重测模式：选择筛选条件后进入全屏重测，只看题目不显示答案，用户自评「会了 / 还不会」，系统更新掌握状态与复习次数，并在结束时给出统计。
6. 复习提醒：根据录入日期与复习次数计算「今日待复习」数量，首页用醒目卡片展示（间隔规则：第 1、3、7、15 天各复习一次）。
7. 导出：导出全部错题的 JSON；导出为打印友好的页面（window.print() + @media print 样式，每道题占一块、图片不跨页）。

【依赖策略】
纯原生 JavaScript + Canvas + fileReader + Blob。零第三方库，零 CDN，不做 OCR，图片内容靠用户自己填写题干。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下表单单列、列表卡片全宽。
2. 数据用 localStorage 持久化，key 前缀 "wrongbook-"；注意 localStorage 约 5MB 上限，写入前检测，接近上限时给出明确提示并建议导出备份。
3. 处理：必填项未填的校验、图片过大/过多的提示、空列表引导文案。
4. 视觉：现代简洁、学科标签用色块区分、难度星级可点选、prefers-color-scheme 暗色模式。
5. 代码行数控制在 650 行以内，图片压缩与复习间隔计算部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Mistake Notebook" web app.

[CONFIG]
Subject: {{SUBJECT}}
Tagging scheme: {{TAGS}}

[FEATURES]
1. Entry form: question text (multiline, required), my answer, correct answer, root cause (required, chosen from presets or custom), knowledge topic / chapter tags, difficulty 1-5 stars, notes.
2. Image support: paste, drag-drop or pick a local image; downscale it with Canvas so the longest side is at most 800px and store it as base64 in localStorage (always compress; warn above 300KB per image).
3. List view: card layout with filters by chapter, root cause and difficulty, sorting by created time or review count, and keyword search across question and answers.
4. Mastery state per entry: Not mastered / Reviewing / Mastered, toggled manually and filterable.
5. Retest mode: after filtering, enter a fullscreen retest showing only questions with no answers; the user self-rates "Got it / Still stuck", which updates mastery and review counts, ending with a summary.
6. Review reminder: compute "due today" from creation date and review count using intervals of 1, 3, 7 and 15 days; surface it prominently on the home screen.
7. Export: JSON of everything, plus a print-friendly page via window.print() with @media print styles (one block per question, images not split across pages).

[DEPENDENCIES]
Vanilla JS + Canvas + FileReader + Blob. Zero libraries, zero CDN. No OCR — users type the question text themselves.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; single-column forms and full-width cards at 375px.
2. localStorage with key prefix "wrongbook-"; remember the ~5MB quota — check before writing and warn with an export-backup suggestion when nearing it.
3. Required-field validation, image size/quantity warnings, empty-list guidance.
4. Modern clean UI: colored subject tags, clickable star difficulty, prefers-color-scheme dark mode.
5. Keep under 650 lines; comment the image compression and review interval logic.
````
