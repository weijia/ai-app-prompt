# 单词卡片记忆

> 翻转卡片 + 艾宾浩斯复习队列 + 发音朗读 · 难度：★★☆ · 约 3 分钟

## 适用场景

背英语单词（也可背任何外语），按遗忘曲线安排复习顺序。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{语种}}` | 背什么语言 | 「英语」 |
| `{{初始词表}}` | 想预置的词 | 「abandon, benefit, compare…」留空则由用户自行录入 |

## 提示词（中文版）

````text
请生成一个「单词卡片记忆」单文件网页应用。

【配置】
语种：{{语种}}
初始词表（可为空）：{{初始词表}}

【功能要求】
1. 卡片组管理：创建多个词包（如「四级核心」「旅行常用」），每个词包含：正面（单词）、背面（释义）、音标、例句、所属词包。支持增删改与批量粘贴导入（每行一条，用 Tab 或 —— 分隔正面与背面）。
2. 学习模式：3D 翻转卡片（CSS transform rotateY + perspective），点击或空格翻面；提供「认识 / 模糊 / 不认识」三档自评。
3. 复习算法（艾宾浩斯简化版，逻辑写在代码里）：
   - 每张卡维护 { interval（天）, ease（难度系数）, due（下次复习日期）, reps（复习次数）, lapses（遗忘次数） }
   - 认识：interval = interval * ease（首次为 1 天），ease 略增
   - 模糊：interval 不变或减少一半，ease 略降
   - 不认识：reps 归零相关计数，interval 重置为 0（当天再来），lapses + 1
   - 每天优先展示 due <= 今天 的卡片，全部完成后提示「今日任务已完成」
4. 发音：使用 window.speechSynthesis 调用系统语音朗读单词，lang 根据语种设置（英语用 en-US）；不支持时隐藏按钮而不是报错。零第三方依赖。
5. 统计：累计学习卡数、今日复习数、掌握度分布（新卡/学习中/已掌握三档环形图，纯 CSS conic-gradient 实现）、连续打卡天数。
6. 设置：每日新卡上限、每日复习上限、是否自动发音。

【依赖策略】
纯原生 JavaScript + CSS 3D + speechSynthesis API，零第三方库，零 CDN。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下卡片占满宽度、按钮单手可及（底部大按钮）。
2. 数据用 localStorage 持久化，key 前缀 "flashcard-"，提供「导出 JSON / 导入 JSON」。
3. 处理：空词包（引导去添加/导入）、今日任务完成后的空状态、非法粘贴格式提示。
4. 视觉：现代简洁、卡片翻转动画 400ms、三档按钮用绿/黄/红区分、prefers-color-scheme 暗色模式、尊重 prefers-reduced-motion。
5. 代码总量建议控制在 650 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。复习算法部分加中文注释。
````

## 生成后自检清单

- [ ] 点击卡片能翻面，动画不卡顿
- [ ] 点「不认识」后这张卡当天会再次出现
- [ ] 第二天再打开，到期卡片排在前面
- [ ] 朗读按钮点了有声音（无语音包时按钮合理处理）
- [ ] 导入粘贴的多行能正确拆成正反面
