# 二维码名片

> 文本/网址转二维码 + 样式定制 + 下载 PNG（自研编码器，零依赖） · 难度：★★★ · 约 4 分钟

## 适用场景

把网址、Wi-Fi 配置、联系方式做成二维码保存下来打印。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{主要用途}}` | 常生成什么类型 | 「店铺收款链接和 Wi-Fi 分享」 |
| `{{默认内容}}` | 打开时的示例内容 | 「https://example.com」 |

## 提示词（中文版）

````text
请生成一个「二维码生成器」单文件网页应用。

【背景】
主要用途：{{主要用途}}
默认内容：{{默认内容}}

【技术核心（重要，请认真实现）】
请内联一个精简版的 QR Code 编码器（基于 QR Model 2 / 字节模式 / 纠错级别选择），用纯 JavaScript 实现，禁止引用 qrcode.js 等第三方 CDN。
实现要点：
1. 支持字节模式（Byte mode），输入 UTF-8 编码（先用 TextEncoder 转字节数组）。
2. 支持纠错级别 L / M / Q / H 四档可选，默认 M。
3. 自动根据数据长度选择版本 1–10；数据量过大时提示「内容过长，请缩短后重试」而不是崩溃。
4. 包含 Reed–Solomon 纠错多项式计算、掩码图案（8 种掩码自动取罚分最低者）、格式信息与版本信息的放置（版本 1–6 无需版本信息区）。
5. 最终把 0/1 矩阵绘制到 canvas 上，每个模块一个方块。
若你认为完整实现过于困难，可以采用「先写死 RS 查表 + 标准掩码模板」的稳妥写法，但必须保证生成的二维码能被手机正常扫出来。

【功能要求】
1. 左侧表单：内容输入框（必填，支持多行）、纠错级别选择、尺寸滑杆（128–512px）、前景色/背景色选择器、边距滑杆。
2. 实时预览：输入变化 300ms 防抖后重新绘制。
3. 下载按钮：导出 PNG（canvas.toDataURL），文件名带时间戳。
4. 快捷键内容类型：点击「网址 / 文本 / Wi-Fi / 名片 vCard」按钮，自动把输入框切成对应的结构化表单（Wi-Fi 则拆成 SSID、密码、加密方式并拼成 WIFI:T:WPA;S:xxx;P:xxx;;）。
5. 中间 Logo 选项：可在二维码中心叠加一块纯色区域留白云（注意：会降低识别率，界面需给出说明）。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
纯原生 JavaScript + canvas。零第三方库，零 CDN。所有计算在本地完成，不上传任何内容到服务器。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用。
2. 处理空输入（禁止绘制）、超长内容（友好提示）、canvas 导出失败（错误 toast）。
3. 视觉：现代简洁、圆角卡片、卡片预览区居中显示二维码、prefers-color-scheme 暗色模式。
4. 代码总量建议控制在 800 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。编码器部分用中文注释标清楚各步骤。
````

## 生成后自检清单

- [ ] 用手机微信/相机扫生成的二维码能正常打开链接
- [ ] 中文内容生成的码扫出来不是乱码
- [ ] Wi-Fi 按钮拼出的字符串被手机识别为 Wi-Fi 配置
- [ ] 下载下来的 PNG 背景是白色而不是透明（安卓看图可能变全黑）
- [ ] 代码里没有任何外链

## 常用追问

1. 「加批量生成：每行一个内容，打包成 ZIP」（提醒：需引入压缩逻辑，要求手写 store 模式 zip）
2. 「支持导出 SVG 格式以便印刷」
3. 「加历史记录面板，保存最近 10 条到本地」
