# 密码生成器

> 强度可调 + 100% 本地生成不上网 + 强度可视化 · 难度：★☆☆ · 约 2 分钟

## 适用场景

注册账号时生成强密码。整个过程在浏览器本地完成，密码不会被记录或上传。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{默认长度}}` | 默认生成几位 | 「16」 |
| `{{额外要求}}` | 特殊限制 | 「不能含易混淆字符 0O1lI」 |

## 提示词（中文版）

````text
请生成一个「密码生成器」单文件网页应用。

【配置】
默认长度：{{默认长度}}
额外要求：{{额外要求}}

【功能要求】
1. 长度滑杆 6–64，实时显示当前数值。
2. 字符集开关：小写字母、大写字母、数字、符号（可多选，至少保留一项，全不选时给出错误提示）。
3. 排除易混淆字符选项：0 O 1 l I | 等。
4. 生成按钮 + 一键复制按钮（复制用 navigator.clipboard，失败时降级为 document.execCommand 方案）。
5. 强度可视化：估算密码熵值（bits = length * log2(字符集大小)），分四档（弱 < 40、中 40–60、强 60–80、极强 > 80）用颜色进度条显示，并给出一句评价文案。
6. 批量生成：一次生成 10 条列表供挑选，点击任意一条即复制。
7. 可选「助记式密码」模式：从内置中文词表里随机取 4 个词 + 数字 + 符号拼成便于记忆的长密码（词表直接内联在代码里）。
8. 密码 History 只保存在内存中并提供「清空」按钮，明确不写入 localStorage。

【安全要求（必须写出并在页面上向用户声明）】
1. 随机源必须使用 crypto.getRandomValues()，且用拒绝采样法避免模偏差（modulo bias），禁止使用 Math.random()。
2. 页面不得包含任何网络请求：不得有 fetch / XMLHttpRequest / form action / 外链统计脚本。生成结果不上传、不写入 localStorage、不输出到 console。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN，零外部资源。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用。
2. 密码展示区用等宽字体并支持「显示/隐藏」切换；复制后有明确 toast 反馈。
3. 至少一个「看起来不错」的视觉：大号密码卡片、细粒度滑杆、彩条强度条、prefers-color-scheme 暗色模式。
4. 代码行数控制在 450 行以内，关键安全点加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Password Generator" web app.

[CONFIG]
Default length: {{LEN}}
Extra constraints: {{EXTRA}}

[FEATURES]
1. Length slider 6-64 with a live value readout.
2. Character set toggles: lowercase, uppercase, digits, symbols (at least one must stay enabled, else show an error).
3. Option to exclude look-alike characters: 0 O 1 l I | etc.
4. Generate button plus one-click copy (navigator.clipboard, falling back to document.execCommand).
5. Strength meter: estimate entropy bits = length * log2(alphabet size), map to four tiers (weak < 40, fair 40-60, strong 60-80, excellent > 80) shown as a colored bar with a one-line verdict.
6. Batch mode: generate 10 candidates at once; click any to copy.
7. Optional passphrase mode: 4 random words from an inline Chinese word list + digits + symbols, easier to remember (embed the word list directly).
8. Generated history lives in memory only, with a Clear button. Explicitly do NOT write it to localStorage.

[SECURITY — REQUIRED, and state them visibly in the page]
1. Use crypto.getRandomValues() with rejection sampling to avoid modulo bias. Never Math.random().
2. Zero network activity: no fetch / XMLHttpRequest / form action / external analytics. Nothing is uploaded, nothing persisted to localStorage, nothing logged to console.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[DEPENDENCIES]
Vanilla JS only. Zero libraries, zero CDN, zero external assets.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta, usable at 375px.
2. Monospace password display with show/hide toggle; copy shows a clear toast.
3. Polished visuals: big password card, fine-grained slider, colored strength bar, prefers-color-scheme dark mode.
4. Keep under 450 lines; comment the security-critical parts.
````

## 生成后自检清单

- [ ] 代码里搜不到 `Math.random`
- [ ] 代码里搜不到 `fetch(`、`http` 外链
- [ ] 只勾「数字」时也能生成，且熵值评估随之变化
- [ ] 复制按钮在自己浏览器里确实能粘贴出来
- [ ] 刷新页面后历史密码清空
