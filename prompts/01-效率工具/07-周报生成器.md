# 周报生成器

> 填要点 → 自动套模板成文 → 一键复制 · 难度：★☆☆ · 约 2 分钟

## 适用场景

每周花两分钟填要点，自动生成结构完整、语气得体的周报正文。所有处理在本地完成，不联网。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{职业角色}}` | 你的岗位 | 「后端开发工程师」 |
| `{{周报模板}}` | 公司要求的板块 | 「本周完成 / 下周计划 / 风险与支持」 |

## 提示词（中文版）

````text
请生成一个「周报生成器」单文件网页应用（基于本地模板与规则自动生成，不联网不调 AI 接口）。

【配置】
我的岗位：{{职业角色}}
周报板块：{{周报模板}}

【功能要求】
1. 结构化表单：按上述板块各一个多行输入框，每行填一条要点；额外提供「本周亮点」「本周数据」「需要协助」等可选字段。
2. 实时预览区：输入的同时在右侧（窄屏在下方）生成 Markdown 格式的周报正文。
3. 本地润色能力（用规则实现，不要调用任何外部 AI 接口）：
   - 自动为每条要点补上动词开头（检测缺少动词时前缀「推进」「完成」「优化」等，基于内置动词表与岗位关键词匹配）
   - 自动去除重复空格与结尾句号不统一问题
   - 把「xx%」「xx 人天」等数字统一加粗
   - 按岗位内置词库把口语替换成职场表达（例如「搞定了」→「已完成」）
4. 模板切换：提供「简洁版 / 详细版 / 面向管理层」三种排版模板，实时切换。
5. 历史周报：每次保存一条带日期的记录，可查看和复制历史周报（localStorage 持久化）。
6. 导出：一键复制 Markdown、导出 .md 文件、导出纯文本。
7. 字数统计与「预计领导阅读时间」。

【禁止事项】
不得向任何外部地址发起请求；不得要求用户填 API Key；所有润色均为本地规则或内置词库实现。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN。Markdown 预览用简单的纯文本排版呈现即可，不需要渲染器。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用。
2. 数据用 localStorage 持久化，key 前缀 "weekly-"，提供「导出 JSON / 导入 JSON」。
3. 处理空输入（预览区显示引导文案）、复制失败降级（execCommand）、成功 toast。
4. 视觉：现代简洁、左表单右预览的双栏卡片布局、预览区等宽字体、prefers-color-scheme 暗色模式。
5. 代码行数控制在 550 行以内，润色规则部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Weekly Report Generator" web app that works entirely through local templates and rules — no network calls, no AI API.

[CONFIG]
My role: {{ROLE}}
Report sections: {{SECTIONS}}

[FEATURES]
1. Structured form: one multiline input per section, one bullet per line; optional extra fields Highlights / Metrics / Help Needed.
2. Live preview of the Markdown report beside the form (below it on narrow screens).
3. Local polishing via rules — never call an external AI service:
   - prepend a leading verb when a bullet lacks one (matched from a built-in verb table and role keywords: Drove / Completed / Optimized)
   - normalize duplicate spaces and inconsistent trailing periods
   - bold numeric values like 12% or 3 person-days
   - replace casual wording with workplace phrasing using a built-in dictionary (e.g. "wrapped up" -> "completed")
4. Three layout templates: Concise / Detailed / Executive-facing, switchable live.
5. Report history: save dated entries, browse and copy past reports (localStorage).
6. Export: copy Markdown, download .md, download plain text.
7. Word count and "estimated reading time".

[PROHIBITED]
No external requests, no API key prompts. All polishing is local rules / embedded dictionaries.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[DEPENDENCIES]
Vanilla JS only, zero libraries, zero CDN. Plain monospace preview is fine — no Markdown renderer needed.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta, usable at 375px.
2. localStorage with key prefix "weekly-"; Export/Import JSON.
3. Handle empty input (show guidance in preview), copy fallback via execCommand, success toasts.
4. Modern clean two-column card layout, monospace preview, prefers-color-scheme dark mode.
5. Keep under 550 lines; comment the polishing rules.
````
