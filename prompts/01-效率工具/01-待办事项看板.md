# 待办事项看板

> 拖拽式三列看板 + 优先级 + 截止提醒 · 难度：★★☆ · 约 3 分钟 · 适用：豆包 / 元宝

## 适用场景

个人或小团队的任务流转（待办 / 进行中 / 已完成），替代不便安装的项目管理软件。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{使用场景}}` | 用来管什么 | 「家里装修的进度」 |
| `{{列定义}}` | 看板列名 | 「待办 / 进行中 / 已完成」 |

## 提示词（中文版）

````text
请生成一个「待办事项看板」单文件网页应用。

【背景】
使用场景：{{使用场景}}
看板列：{{列定义}}

【功能要求】
1. 三列（或多列）看板布局，每列顶部显示卡片数量。
2. 新建任务：标题（必填）、备注、优先级（高/中/低）、截止日期、所属列。
3. 卡片支持拖拽换列，同时在触屏上支持拖动（使用 HTML5 Drag & Drop 时必须补充 pointer 事件方案实现触屏兼容）。
4. 卡片可編集、删除，删除时弹出确认。
5. 筛选器：按优先级筛选、按关键词搜索、只看今天到期/已逾期。
6. 顶部统计条：总数、今日到期数、逾期数、本周完成数。
7. 逾期任务卡片左侧显示红色竖条，标题旁显示红色「逾期」标签。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不拆文件，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
纯原生 JavaScript 实现，不引入任何第三方库，不使用任何 CDN。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽手机上三列改为上下堆叠或横向滑动切换。
2. 数据用 localStorage 持久化，key 前缀 "kanban-"，并提供「导出 JSON / 导入 JSON」按钮。
3. 处理空状态（每列显示「暂无任务，点击 + 添加」）、表单校验（标题不能为空）、成功/失败提示（右上角 toast）。
4. 视觉：现代简洁、圆角卡片、主色 #2563eb、hover/focus 反馈明显、prefers-color-scheme 暗色模式；优先级用三色小圆点区分。
5. 代码总量建议控制在 600 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。关键函数加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Kanban board" web app.

[CONTEXT]
Use case: {{USE_CASE}}
Columns: {{COLUMNS}}

[FEATURES]
1. Column layout with a card count in each header.
2. Create task: title (required), notes, priority (high/medium/low), due date, target column.
3. Drag and drop cards between columns; HTML5 Drag & Drop must be complemented with pointer events so it also works on touch screens.
4. Edit and delete cards; confirm before deleting.
5. Filters: by priority, keyword search, "due today / overdue only".
6. Top stat bar: total, due today, overdue, completed this week.
7. Overdue cards get a red left border and a red "Overdue" badge next to the title.

[DELIVERY]
One complete index.html with HTML/CSS/JS inline. No npm, no build tools.
Reply structure: one-line summary -> exactly ONE ```html full code block (no ellipsis) -> 3 lines of usage notes.

[DEPENDENCIES]
Vanilla JavaScript only. No third-party libraries, no CDN at all.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px switch to stacked columns or horizontal swipe.
2. Persist to localStorage with key prefix "kanban-"; provide Export JSON / Import JSON buttons.
3. Handle empty states ("No tasks, click + to add"), validation (title required), success/error toasts top-right.
4. Modern clean UI: rounded cards, primary #2563eb, clear hover/focus states, prefers-color-scheme dark mode; priority shown as three colored dots.
5. Aim for about 600 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment key functions.
````

## 生成后自检清单

- [ ] 鼠标能拖动卡片换列，触屏或模拟移动也能拖
- [ ] 改了优先级后颜色标签立即变化
- [ ] 逾期任务有红色标记，顶部统计数字正确
- [ ] 刷新后数据仍在，导出 JSON 能再导入
- [ ] 手机上三列不挤成一团

## 常用追问

1. 「给每张卡片加子任务清单和完成进度条」
2. 「加日历视图，按截止日期展示月历」
3. 「改成对比度更高的配色，并支持自定义主色」
