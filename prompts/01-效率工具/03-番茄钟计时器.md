# 番茄钟计时器

> 番茄计时 + 任务绑定 + 完成统计，含提示音（本地合成） · 难度：★★☆ · 约 3 分钟

## 适用场景

专注工作/学习计时，配合任务清单看自己今天专注了多久。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{专注时长}}` | 一个番茄多少分钟 | 「25」 |
| `{{短休时长}}` | 短休息分钟数 | 「5」 |
| `{{长休间隔}}` | 几个番茄后长休 | 「4」 |

## 提示词（中文版）

````text
请生成一个「番茄钟计时器」单文件网页应用。

【配置】
专注时长：{{专注时长}} 分钟；短休息：{{短休时长}} 分钟；每 {{长休间隔}} 个番茄后长休息 15 分钟。

【功能要求】
1. 中央大号倒计时（mm:ss），下方显示当前阶段：专注 / 短休 / 长休 / 已暂停。
2. 环形进度：用 SVG circle 的 stroke-dasharray 实现圆环随剩余时间收缩，颜色按阶段区分。
3. 控制按钮：开始 / 暂停 / 继续 / 重置（重置需确认）。
4. 任务清单：可添加任务，点击任务把它设为「当前专注对象」，完成的番茄数记到该任务上。
5. 结束提醒：使用 Web Audio API 本地合成提示音（不同阶段用不同频率的短促音），不要用外链音频文件；同时切换浏览器标签页标题显示剩余时间。
6. 今日统计：完成番茄数、累计专注分钟数；并提供最近 7 天专注分钟柱状图（纯 CSS 实现）。
7. 设置面板：可修改专注/短休/长休时长、是否自动开始下一阶段。

【关键正确性要求】
计时必须基于时间戳计算（记录 endTime = Date.now() + duration），而不是简单的 setInterval 自减；
这样即使切到后台标签页被浏览器降频，回到页面时依然能算出正确剩余时间。setInterval 只负责刷新显示。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
纯原生 JavaScript + 内联 SVG，零第三方库，零 CDN。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用，按钮支持键盘空格/回车操作。
2. 数据用 localStorage 持久化，key 前缀 "pomodoro-"，提供「导出 JSON / 导入 JSON」。
3. 处理空状态（任务列表为空时的引导）、非法输入校验、成功/失败 toast。
4. 视觉：现代简洁、大留白、专注态背景安静收敛、休息态轻松活泼、prefers-color-scheme 暗色模式。
5. 代码行数控制在 600 行以内，关键函数加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Pomodoro Timer" web app.

[CONFIG]
Focus: {{FOCUS}} min; short break: {{SHORT}} min; after every {{CYCLE}} pomodoros take a 15-min long break.

[FEATURES]
1. Large central countdown (mm:ss) with current phase below: Focus / Short break / Long break / Paused.
2. Ring progress using inline SVG circle stroke-dasharray that shrinks with remaining time, color-coded per phase.
3. Controls: Start / Pause / Resume / Reset (reset requires confirmation).
4. Task list: add tasks, tap one to set it as the current focus target, completed pomodoros count toward that task.
5. End alert: synthesize a short beep locally with the Web Audio API (different pitch per phase) — do not link external audio files. Also reflect remaining time in the document title.
6. Today stats: pomodoros completed, total focus minutes, plus a 7-day focus bar chart built with pure CSS.
7. Settings panel: edit focus/short/long durations and toggle auto-start of next phase.

[CORRECTNESS — CRITICAL]
Compute remaining time from timestamps (store endTime = Date.now() + duration), not by decrementing in setInterval.
Background tabs get throttled, and only timestamp math gives the correct remaining time on return. setInterval is for repainting only.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[DEPENDENCIES]
Vanilla JS + inline SVG. Zero libraries, zero CDN.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta, usable at 375px, buttons operable via Space/Enter.
2. localStorage with key prefix "pomodoro-"; Export JSON / Import JSON.
3. Empty state for the task list, validation, success/error toasts.
4. Modern clean visuals: calm focus mode, lighter break mode, generous whitespace, prefers-color-scheme dark mode.
5. Keep under 600 lines; comment key functions.
````

## 生成后自检清单

- [ ] 切到其他标签页 1 分钟再回来，剩余时间依然准确
- [ ] 结束时能听到声音（首次交互后才允许播放，符合浏览器策略）
- [ ] 标签页标题显示剩余时间
- [ ] 完成后任务的番茄数 +1
- [ ] 最近 7 天柱状图数据正确（断网也不受影响）
