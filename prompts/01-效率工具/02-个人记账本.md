# 个人记账本

> 收支记录 + 分类饼图 + 月度统计，全程本地不上网 · 难度：★★☆ · 约 3 分钟 · 适用：豆包 / 元宝

## 适用场景

日常流水记录，看钱花在哪。所有数据只存在自己浏览器里，不上传任何服务器。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{支出分类}}` | 想要的分类 | 「餐饮、交通、日用、娱乐、医疗、人情、其他」 |
| `{{收入分类}}` | 收入来源 | 「工资、副业、理财、红包」 |
| `{{货币符号}}` | 币种 | 「¥」 |

## 提示词（中文版）

````text
请生成一个「个人记账本」单文件网页应用。

【配置】
支出分类：{{支出分类}}
收入分类：{{收入分类}}
货币符号：{{货币符号}}

【功能要求】
1. 顶部概览卡片：本月收入、本月支出、本月结余（结余为负时显示红色）。
2. 记一笔：金额（必填，数字校验，最多两位小数）、类型（支出/收入）、分类、日期（默认今天）、备注、可选标签。
3. 明细列表：按日期倒序分组，每天显示小计；支持编辑与删除（删除需确认）。
4. 月份切换器：上一月/下一月，所有统计随月份联动。
5. 图表区（两条二选一，见依赖策略）：支出分类占比饼图 + 近 6 个月收支对比柱状图。
6. 分类筛选与时间范围搜索。
7. 导出 CSV 按钮，便于用 Excel 打开。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不使用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略】
优先用原生方式实现：用 CSS conic-gradient 画饼图并用原生图表 API 不可行时，改用「横向条形占比图」（纯 CSS div 宽度百分比实现）+ 数字百分比，这样零依赖且不会白屏。
若你坚持用 ECharts，则必须满足：地址为 https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js（版本号写死），且必须实现 onerror 降级：加载失败时自动切换为上面说的纯 CSS 条形占比图，并在页面显示黄色提示条。禁止使用 jsdelivr / unpkg / cdnjs。

【安全与工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽可用，底部固定「记一笔」悬浮按钮。
2. 金额计算请特别注意浮点数精度：统一按「分」为单位存储整数，展示时再除以 100。
3. 数据用 localStorage 持久化，key 前缀 "ledger-"，提供「导出 JSON / 导入 JSON」。
4. 处理空状态（本月还没有记录时的引导文案）、表单校验（金额必须为正数）、成功/失败 toast。
5. 视觉：现代简洁、圆角卡片、支出红收入绿的主色语义、hover/focus 反馈、prefers-color-scheme 暗色模式。
6. 所有计算在本地完成，明确不得向任何外部地址发送用户数据。
7. 代码总量建议控制在 650 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。关键函数加中文注释。
````

## 生成后自检清单

- [ ] 记一笔后本月三个统计数字都对得上
- [ ] 金额没有出现 0.30000000000000004 这类浮点误差
- [ ] 切到上个月数据正确隔离
- [ ] 图表即使断网也不白屏（有降级）
- [ ] 导出的 CSV 用 Excel 打开中文不乱码（需带 UTF-8 BOM）
