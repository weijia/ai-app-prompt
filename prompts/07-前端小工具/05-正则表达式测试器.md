# 正则表达式测试器

> 实时匹配高亮 + 分组展示 + 常用片段库 · 难度：★★☆ · 约 3 分钟

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{常用 flag}}` | 默认开启哪些标志 | 「g、i、m」 |
| `{{常用场景}}` | 平时校验什么 | 「手机号、邮箱、身份证、日期」 |

## 提示词（中文版）

````text
请生成一个「正则表达式测试器」单文件网页应用，全部本地运行。

【配置】
默认开启的 flags：{{常用 flag}}
我常校验的内容：{{常用场景}}

【功能要求】
1. 输入区：正则输入框（用 /pattern/flags 的形式展示，输入框两侧固定显示斜杠与 flag 区）、测试文本域（多行）。
2. 标志开关：g / i / m / s / u / y 六个开关，带简短中文说明（如 s 让 . 匹配换行符）。
3. 实时匹配：输入变化后 200ms 防抖执行匹配，把命中的子串在原文下方的结果面板里高亮显示（背景色区分奇数偶数次匹配以便分辨相邻匹配）。
4. 匹配详情列表：每次命中显示索引位置、完整匹配串、以及捕获组（有命名组时显示组名），点击某条可滚动并高亮到对应位置。
5. 替换模式：提供替换输入框，支持 $1、$<name>、$& 等引用语法，实时预览替换结果并可复制。
6. 错误提示：正则语法错误时（try/catch 包裹 new RegExp）在输入框下方红字显示原因，并且绝不因报错而清空用户输入或崩溃页面。
7. 性能保护（重要）：实现一个简单的灾难性回溯保护——如果单次匹配超过 1 秒仍未结束（用时间检测 + 限制替换/查询循环次数），中断匹配并提示「该正则可能存在灾难性回溯，已停止执行」；同时对超过 10000 次匹配的结果做截断提示。
8. 常用正则库：内置 15 条常用片段（手机号、邮箱、身份证、URL、IPv4、日期、中文字符、邮政编码、车牌号、强密码、十六进制颜色、QQ 号、微信号等），点击插入并用 {{常用场景}} 相关示例文本填充测试框；每条注明其匹配口径（宽松/严格）。
9. 收藏：用户可保存自己的正则（命名 + 表达式 + flags）到 localStorage，支持载入删除。

【安全要求】
使用 new RegExp 时必须处理用户输入非法导致的异常；渲染测试文本与结果时必须 HTML 转义后再插入，防止 XSS。

【依赖策略】
纯原生 JavaScript，零第三方库，零 CDN。不使用任何代码编辑器库。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下改为上下堆叠的输入区。
2. 数据用 localStorage 持久化，key 前缀 "regextester-"（保存收藏的正则与最近一次输入）。
3. 处理：空正则/空文本的提示、极端长文本的渲染节流、无效 flag 组合（如同时使用 y 与 g 的说明）。
4. 视觉：类似编辑器的双主题、命中高亮用暖黄/青色交替、每个匹配的序号标签、prefers-color-scheme 暗色模式。
5. 页面注明「所有匹配在本地完成，文本不会上传」。
6. 代码总量建议控制在 650 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。灾难性回溯保护与转义部分加中文注释。
````

## 生成后自检清单

- [ ] 输入非法正则时页面不崩、提示清晰
- [ ] 高亮能区分相邻的两个匹配
- [ ] 命名捕获组 `$<name>` 在替换模式里生效
- [ ] 输入导致灾难性回溯的正则时会被中断并提示
- [ ] 粘贴含 HTML 的测试文本不会被渲染执行
