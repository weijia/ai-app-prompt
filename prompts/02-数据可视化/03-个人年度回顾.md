# 个人年度回顾页

> 滚动式数据故事页，像年度报告那样讲述你的一年 · 难度：★★☆ · 约 4 分钟

## 适用场景

年终给自己写一份可分享的年度总结页（阅读、运动、记账等自建数据），截图发朋友圈。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{年份}}` | 哪一年 | 「2026」 |
| `{{记录维度}}` | 想回顾哪些方面 | 「读书、跑步、支出、电影」 |

## 提示词（中文版）

````text
请生成一个「个人年度回顾」单文件网页应用。

【配置】
年份：{{年份}}
希望回顾的维度：{{记录维度}}

【功能要求】
1. 数据录入：每个维度一个卡片，提供简单的「按月录入」表格（12 行输入）+ 手动逐条添加（日期、数值、备注）两种模式；附带「填充示例数据」按钮便于预览效果。
2. 生成故事页：点击「生成我的年度回顾」进入全屏滚动展示模式，逐屏推进，每屏一个主题：
   - 封面：年份大字 + 一句副标题
   - 总览：各维度年度总量（数字从 0 滚动到最终值的入场动画）
   - 逐维度：总计 + 月度柱状图 + 最突出的一天/一月（自动计算并生成一句文案，如「三月是你读书最多的一个月，共 7 本」）
   - 结尾：一句话总结 + 生成日期
3. 滚动体验：每屏高度 100vh，使用 IntersectionObserver 触发入场动画（淡入 + 上移 24px），支持鼠标滚轮与手机滑动推进，右下角进度圆点可点击跳转。
4. 分享：提供「导出 PNG」（逐屏 canvas 截图或整体长图，若实现复杂则改为「打印/另存为 PDF」按钮调用 window.print() 并配套 @media print 样式）；提供「导出 HTML」保存当前数据快照页面。
5. 返回编辑：随时退出展示模式回到数据录入，数据不丢。

【依赖策略】
优先零依赖：柱状图用纯 CSS/div 宽度实现，入场动画用 CSS transition + IntersectionObserver。
若确需更好的图表效果，允许使用 ECharts，地址必须为 https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js（版本号写死），且必须有 onerror 降级到 CSS 柱状图 + 黄色提示条。禁止 jsdelivr / unpkg / cdnjs。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽每屏都能完整显示，文字不溢出。
2. 数据用 localStorage 持久化，key 前缀 "yearly-"，提供「导出 JSON / 导入 JSON」。
3. 处理：某维度全年为空时跳过该屏而不是留空白、数值非法时的校验提示。
4. 视觉：深色渐变背景 + 大字号 + 强调色（可在设置里切换 3 套配色）、数字用等宽或衬线字体增强质感、尊重 prefers-reduced-motion（用户开启减弱动效时跳过动画）。
5. 代码行数控制在 700 行以内，关键函数加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Personal Year in Review" web app.

[CONFIG]
Year: {{YEAR}}
Dimensions to review: {{DIMENSIONS}}

[FEATURES]
1. Data entry: one card per dimension with a simple 12-row monthly input table, plus manual item entry (date, value, note); include a "Fill with sample data" button to preview.
2. Story mode: clicking "Generate my year in review" enters a fullscreen scroll experience, one screen per topic:
   - Cover: giant year number + subtitle
   - Overview: per-dimension yearly totals with count-up animation from 0
   - Per dimension: total + monthly bar chart + the standout day/month, auto-summarized in a sentence (e.g. "March was your biggest reading month: 7 books")
   - Closing: one-line summary + generation date
3. Scroll UX: 100vh screens, IntersectionObserver triggering enter animations (fade + 24px rise), wheel and touch swipe both advance, clickable progress dots bottom-right.
4. Sharing: "Export PNG" (per-screen canvas capture or one long image; if too complex, provide "Save as PDF" calling window.print() with matching @media print styles); plus "Export HTML" saving a snapshot page with current data.
5. Exit story mode back to editing at any time without losing data.

[DEPENDENCIES]
Zero-dependency preferred: bar charts via CSS div widths, animations via CSS transitions + IntersectionObserver.
If better charts are needed, ECharts is allowed only from https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js with a pinned version AND an onerror fallback to CSS bars plus a yellow banner. No jsdelivr / unpkg / cdnjs.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; each screen fits 375px without text overflow.
2. localStorage with key prefix "yearly-"; Export/Import JSON.
3. Skip a dimension entirely when empty instead of showing a blank screen; validate numeric input.
4. Dark gradient background, large type, accent color with 3 selectable palettes, monospace/serif numerals, and respect prefers-reduced-motion (skip animations when reduced).
5. Keep under 700 lines; comment key functions.
````

## 生成后自检清单

- [ ] 每个维度都能录入并生成对应的一屏
- [ ] 某一维度为空时被跳过，不出现空白屏
- [ ] 手机竖屏上下滑动能逐屏推进
- [ ] 断网也不影响（图表有降级）
- [ ] 打印预览里排版正常，没有被裁切
