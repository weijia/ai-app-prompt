# 销售数据仪表盘

> KPI 卡片 + 多图表联动 + 筛选器，支持粘贴自己的数据 · 难度：★★★ · 约 4 分钟

## 适用场景

把一份销售明细（日期/区域/产品/金额）变成能看的看板。数据本地处理，不上传。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{业务字段}}` | 数据里有哪些列 | 「日期、省份、产品线、销售员、金额、数量」 |
| `{{关注指标}}` | 最想看的指标 | 「月度趋势、区域排名、Top10 产品」 |

## 提示词（中文版）

````text
请生成一个「销售数据仪表盘」单文件网页应用。

【配置】
我的数据字段：{{业务字段}}
我最关注的指标：{{关注指标}}

【功能要求】
1. 数据入口三选一：粘贴表格文本（Tab 或逗号分隔，第一行为表头）／上传 CSV 文件（FileReader 本地读取）／使用内置示例数据按钮。
2. 自动字段映射：解析后让用户选择哪一列是「日期」「分类维度」「金额」，列识别失败时提供手动下拉选择。
3. 顶部 KPI 卡片：总销售额、订单数、客单价、环比（若能算出上一周期）或同比增长；数字使用千分位与中文单位（万/亿）自动缩写。
4. 图表区：
   - 时间趋势折线图（按日/周/月聚合切换）
   - 分类维度柱状图 Top 10
   - 构成占比饼图（环形）
   - 全部使用同一份数据，筛选变化时三个图联动刷新
5. 筛选器：时间范围（起止日期）、分类多选、关键词搜索；筛选结果实时反映到 KPI 与图表。
6. 明细表格：底部展示筛选后的明细，支持点击列头排序，每页 20 条带分页。
7. 导出：导出当前筛选结果为 CSV。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【依赖策略（严格遵守）】
只可使用 ECharts，地址固定为 https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js （版本号必须写死）。
必须实现 onerror 降级：若 window.echarts 不存在，则把三个图表位置替换为「原生 HTML 表格 + 纯 CSS 横向条形图」，并在页面顶部显示黄色提示条「图表库加载失败，已降级为表格视图」，绝不白屏。
禁止使用 jsdelivr / unpkg / cdnjs 以及任何其它第三方库。
resize 时必须调用图表实例的 resize()，并在 ResizeObserver 中处理容器尺寸变化。

【数据正确性要求】
1. 金额统一以「分」或 parseFloat 后保留两位计算，展示时格式化；避免浮点累加误差（建议使用整数累加后再除）。
2. 日期解析兼容 YYYY-MM-DD、YYYY/MM/DD、YYYY-MM-DD HH:mm 三种格式，非法日期归入「未知日期」分组而不是丢弃。
3. 空数据、只有一行数据、日期列全为空等情况下不得报错。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta）；375px 宽下图表纵向排列且高度自适应，KPI 卡片两列显示。
2. 数据集用 localStorage 持久化，key 前缀 "dash-"，提供「导出 JSON / 导入 JSON」。
3. 空状态引导、输入校验、成功/失败 toast。
4. 视觉：现代简洁、浅灰背景 + 白色圆角卡片、统一主色、prefers-color-scheme 暗色模式（暗色下图表主题需同步切换）。
5. 代码总量建议控制在 750 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。关键函数加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Sales Dashboard" web app.

[CONFIG]
My data fields: {{FIELDS}}
Metrics I care about: {{METRICS}}

[FEATURES]
1. Three data inputs: paste tabular text (tab or comma separated, first row as header) / upload a CSV via FileReader / load built-in sample data.
2. Auto field mapping: after parsing, let the user pick which column is Date, which is the category dimension, and which is the amount; fall back to manual dropdowns when detection fails.
3. Top KPI cards: total revenue, order count, average order value, period-over-period change when computable; format numbers with thousand separators and K/M/B style abbreviations.
4. Charts:
   - time-series line chart with day/week/month granularity toggle
   - top-10 bar chart by category dimension
   - donut chart for share composition
   All driven by the same filtered dataset, so they stay in sync.
5. Filters: date range, multi-select categories, keyword search — all reflected instantly in KPIs and charts.
6. Detail table below with sortable headers and pagination (20 rows per page).
7. Export the current filtered result as CSV.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[DEPENDENCIES — STRICT]
ECharts only, pinned: https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js
Implement an onerror fallback: if window.echarts is undefined, replace the three chart slots with native HTML tables plus pure CSS horizontal bar visuals, and show a yellow top banner "Chart library failed to load, falling back to table view". Never render a blank page.
No jsdelivr / unpkg / cdnjs, no other third-party libraries.
Call chart.resize() on container resize via ResizeObserver.

[DATA CORRECTNESS]
1. Accumulate money as integers (cents) before dividing, then format for display — avoid float accumulation error.
2. Support YYYY-MM-DD, YYYY/MM/DD and YYYY-MM-DD HH:mm; invalid dates go to an "Unknown date" bucket rather than being dropped.
3. Handle empty dataset, single-row dataset, and an all-empty date column without throwing.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px charts stack vertically with adaptive height and KPI cards go two-up.
2. Persist the dataset in localStorage with key prefix "dash-"; Export/Import JSON.
3. Empty-state guidance, validation, success/error toasts.
4. Modern clean look: light gray background, white rounded cards, one primary color, prefers-color-scheme dark mode (chart theme must switch too).
5. Aim for about 750 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment key functions.
````

## 生成后自检清单

- [ ] 粘贴一段带表头的表格能正确出图
- [ ] 断网刷新时不白屏，出现降级表格
- [ ] 切换筛选器后 KPI 和三个图表同步更新
- [ ] 窗口缩放后图表跟着变宽（resize 生效）
- [ ] 金额没有浮点误差（比如 0.1+0.2）
