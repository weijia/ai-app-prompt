# 图表类型选择器

> 粘贴数据 → 自动推荐图表 → 多类型一键切换 · 难度：★★☆ · 约 3 分钟

## 适用场景

不确定该用什么图，让工具根据数据结构推荐，并且能快速切着看。

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{数据类型}}` | 常见的输入形式 | 「两列：名称 + 数值」 |
| `{{需要导出}}` | 导出需求 | 「PNG 图片、SVG、配置 JSON」 |

## 提示词（中文版）

````text
请生成一个「图表类型选择器」单文件网页应用。

【背景】
我的数据通常长这样：{{数据类型}}
需要导出：{{需要导出}}

【功能要求】
1. 数据输入：两列表格（标签 / 数值），支持增删行、粘贴整块文本（每行用 Tab 或逗号分隔）自动生成行、以及填充示例数据。
2. 自动推荐：根据数据特征给出推荐图表，推荐规则必须写在代码里：
   - 行数 ≤ 8 且希望看占比 → 推荐饼图/环形图
   - 行数 > 8 → 推荐柱状图
   - 标签可被解析为日期且数量 ≥ 5 → 推荐折线图
   - 数值有正负 → 推荐正负柱状图
   - 数据点 ≤ 30 且有两组数值 → 推荐横向对比条形图
   推荐结果以「推荐」角标展示在前三种图表按钮上。
3. 图表类型一键切换（至少 6 种）：柱状、条形（横向）、折线、面积、饼图、环形、雷达（数据 ≥ 3 项时可用）。
4. 样式微调：主色选择器、是否显示数据标签、是否显示网格线、Y 轴是否从 0 开始、标题输入。
5. 导出：PNG 图片、SVG 源码复制、当前配置导出 JSON / 导入 JSON。
6. 空数据或只有 1 行数据时给出明确引导文案，不要渲染报错。

【依赖策略（严格遵守）】
只可使用 ECharts，地址固定为 https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js（版本号写死）。
必须实现 onerror 降级：加载失败时用纯 CSS 横向条形图 + 数值表格呈现同样的数据，并显示黄色提示条；此时导出 PNG/SVG 按钮自动替换为导出 CSV。绝不白屏。
禁止 jsdelivr / unpkg / cdnjs 及其余第三方库。

【交付格式】
只输出一个完整 index.html，HTML/CSS/JS 全部内联，不用 npm 与构建工具。
回复结构：一句话说明 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行使用说明。

【工程要求】
1. 界面全中文，移动端优先响应式（含 viewport meta），375px 宽下图表高度自适应不小于 260px，操作区折叠为可展开面板。
2. 数据与配置用 localStorage 持久化，key 前缀 "chart-"。
3. 输入校验：数值列必须能转成数字，非法时标红并提示。
4. 视觉：现代简洁、选中图表按钮有高亮态、切换图表时有 200ms 过渡、prefers-color-scheme 暗色模式。
5. 代码总量建议控制在 600 行左右；功能完整性优先于行数——不得为压缩行数而省略功能或用省略号代替代码，超出时只精简注释与冗余写法。推荐规则部分加中文注释。
````

## Prompt (English Version)

````text
Generate a single-file "Chart Type Picker" web app.

[CONTEXT]
My data usually looks like: {{SHAPE}}
Exports needed: {{EXPORTS}}

[FEATURES]
1. Two-column data grid (label / value): add and remove rows, paste a block of text (tab or comma separated per row) to auto-fill rows, plus "Fill sample data".
2. Auto recommendation from data characteristics — encode these rules in code:
   - rows <= 8 and proportions matter -> pie / donut
   - rows > 8 -> bar chart
   - labels parse as dates and count >= 5 -> line chart
   - values include negatives -> diverging bar chart
   - <= 30 points with two value series -> horizontal comparison bars
   Mark the top three suggested chart buttons with a "Recommended" badge.
3. One-click switching across at least 6 types: bar, horizontal bar, line, area, pie, donut, radar (enabled when >= 3 items).
4. Style controls: primary color picker, show data labels, show grid lines, force Y axis to start at zero, chart title input.
5. Export: PNG image, copy SVG source, export/import the current config as JSON.
6. Clear guidance copy for empty or single-row data — never throw while rendering.

[DEPENDENCIES — STRICT]
ECharts only, pinned: https://cdn.staticfile.org/echarts/5.5.0/echarts.min.js
Implement an onerror fallback: on failure render the same data with pure CSS horizontal bars plus a values table and show a yellow banner; swap the PNG/SVG export button for CSV export. Never a blank page.
No jsdelivr / unpkg / cdnjs, no other libraries.

[DELIVERY]
One complete index.html, all inline. No npm, no build tools.
Reply: one-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 usage lines.

[QUALITY]
1. English UI, mobile-first responsive with viewport meta; at 375px the chart is at least 260px tall and the control panel collapses.
2. Persist data and config in localStorage with key prefix "chart-".
3. Validate that the value column parses as numbers; highlight invalid rows in red with a message.
4. Modern clean UI: highlighted selected chart button, 200ms transition when switching, prefers-color-scheme dark mode.
5. Aim for about 600 lines; completeness outranks length — never drop features or use ellipsis to save lines; if it runs over, trim comments and redundancy only. Comment the recommendation rules.
````

## 生成后自检清单

- [ ] 非法数值被标红且不会渲染崩溃
- [ ] 断网时降级为 CSS 条形图
