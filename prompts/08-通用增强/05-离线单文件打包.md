# 离线单文件打包（追问专用）

> 去掉所有 CDN 与外链，做成断网也能跑的纯离线 HTML

## 适用场景

- 页面样式全丢、怀疑 CDN 被墙
- 要发给没网的同事，或想长期存档
- 想放在本地/内网使用

## 提示词（中文版）

````text
请把这个网页应用改造成「完全离线的单文件 HTML」：断开网络、拔掉网线也要 100% 能用，所有依赖都必须内联。

{{原代码}}

【必须完成的改造】
1. 外链依赖处理：逐个检查页面里所有 <script src>、<link href>、图片 URL、字体 URL。
   - 图表类：如果用了 ECharts CDN，改为用纯 CSS + 原生表格/SVG 重新实现同样的图表效果（柱状图用 div 宽度百分比，折线图用内联 SVG polyline，饼图用 conic-gradient 或多个 SVG 扇形路径）。
   - 图标字体：改为内联 SVG icon。
   - 外部字体：改为系统字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif）。
   - 外部图片：改为 CSS 渐变/SVG 绘制，或提示用户改为本地上传。
2. 网络请求清零：删除所有 fetch / XMLHttpRequest / <form action> / 图片 CDN 域名引用；确需网络的地方改为本地计算或手动输入。
3. 输出前自检：改造完成后，请在回复里明确列出「已移除的外部资源清单」与「替代实现方式」，若某项无法替代要直接说明，不可留下外链。
4. 保留原有全部功能与 localStorage 数据结构（key 不许改），界面保持中文，移动端响应式保留。

【输出格式】
离线化程度说明（移除了哪些、用什么替代）→ 唯一的 ```html 完整代码块（禁止省略号）→ 2 行「如何验证离线可用」的操作步骤（例如：断网后双击打开文件，检查是否还有任何请求失败）。

【验证要求】
你输出的代码里不允许出现任何 http:// 或 https:// 开头的资源地址（出现在注释或说明文字里可以，但不能作为 src/href/fetch 目标）。
````

## Prompt (English Version)

````text
Turn this web app into a fully offline single-file HTML: it must work 100% with the network unplugged, with every dependency inlined.

{{CODE}}

[REQUIRED]
1. External resources: audit every <script src>, <link href>, image URL and font URL.
   - Charts: if an ECharts CDN was used, reimplement the same visuals with pure CSS plus native tables/SVG (bars as percentage-width divs, lines as inline SVG polylines, pies via conic-gradient or SVG arc paths).
   - Icon fonts: replace with inline SVG icons.
   - External fonts: switch to a system font stack.
   - External images: draw them with CSS gradients or SVG, or ask the user to upload locally.
2. Zero network: remove all fetch / XMLHttpRequest / <form action> references and any CDN image domains; replace anything network-dependent with local computation or manual input.
3. Self-audit before replying: explicitly list "removed external resources" and "replacement approach" for each. If something can't be replaced, say so instead of leaving the link in.
4. Keep all existing features, keep the localStorage data model and keys unchanged, keep the English UI and mobile responsiveness.

[OUTPUT FORMAT]
Offline-readiness notes (what was removed and substituted) -> exactly ONE ```html full block (no ellipsis) -> 2 lines on how to verify offline behavior (e.g. disconnect and open the file, check that nothing fails to load).

[VERIFICATION]
Your output must contain no http:// or https:// resource URLs as src / href / fetch targets (URLs inside comments or prose are fine).
````

## 验收清单

- [ ] 源码里搜不到任何作为资源地址的 `http`
- [ ] 断网后打开，控制台没有任何加载失败
- [ ] 图表仍有替代展示，不是直接消失
- [ ] localStorage 的 key 没变，老数据还在
- [ ] 文件体积可接受（一般 < 300KB）

## 配套追问

1. 「给页面加 manifest 和 Service Worker，变成可安装 PWA」（提醒：Service Worker 需通过 http 服务打开，file:// 下无效）
2. 「把所有代码压到最小，去掉注释和空行」
