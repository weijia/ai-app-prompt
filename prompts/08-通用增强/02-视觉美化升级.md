# 视觉美化升级（追问专用）

> 指定风格让页面颜值翻倍，功能一行不改

## 占位符说明

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{目标风格}}` | 想要什么感觉 | 「Linear 的极简暗黑风 / Notion 的清爽文档风 / 国潮插画风」 |
| `{{主色}}` | 主色调 | 「靛蓝 #4f46e5 + 青色点缀」 |

## 用法

先告诉它你想要的参考风格。若怕它跑偏，可先追加一句：「先描述你要做的视觉改动方案，我确认后再输出代码」。

## 提示词（中文版）

````text
请在完全不改功能、不改数据结构的前提下，重写这个页面的样式，让它看起来像专业设计师做的作品。

目标视觉风格：{{目标风格}}
主色与配色：{{主色}}

{{原代码}}

【视觉改造清单】
1. 配色体系：用 CSS 变量建立一套色板（--bg / --surface / --text / --text-muted / --primary / --border / --success / --warning / --danger），全站只用变量取色，不再硬编码颜色。同时适配 prefers-color-scheme 暗色模式。
2. 字体层级：建立 4 级字号（标题/小标题/正文/辅助）与统一的行高规则（正文 1.6），中文优先使用系统字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif），不引外部字体。
3. 间距系统：统一使用 4 的倍数（4/8/12/16/24/32/48）作为 margin 与 padding 值，杜绝随意的 13px、17px。
4. 圆角与阴影：统一圆角（卡片 12-16px，按钮 8-12px，标签 999px），阴影分三级（小 hover / 中卡片 / 大弹窗），不要到处都是重阴影。
5. 留白：页面最大宽度控制在 1200px 内居中，区块间距 ≥ 48px，让内容呼吸。
6. 动效：统一 150-250ms 的 ease-out 过渡；hover 轻微上浮 + 阴影加深；列表项入场做错落的淡入（stagger 40ms）；遵守 prefers-reduced-motion。
7. 反馈：按钮要有 loading / disabled / hover / active 四态；空状态要有插画感的占位（用 CSS 图形或 emoji，不外链图片）；错误状态用红色边框 + 图标 + 说明文字。
8. 图标：统一为内联 SVG（stroke-width 1.5-2，尺寸 16/20/24 三档），风格保持一致，禁止混用 emoji 与 SVG 图标表达同一类含义。
9. 细节：滚动条美化、选中文字的高亮色、焦点圈的样式统一、打印样式（若是文档类页面）。

【不要做】
不改动任何业务逻辑，不改动 localStorage 的 key 与数据结构，不新增第三方依赖，不引入外部图片与字体。

【输出】
一句话说明视觉改动思路 → 唯一的 ```html 完整代码块（禁止省略号）→ 简短说明如何用这套新色板做二次定制。
````

## 验收清单

- [ ] 全站颜色都走 CSS 变量，改一个变量能整体换色
- [ ] 暗色模式下对比度仍然足够
- [ ] 没有硬编码的奇怪间距值
- [ ] 所有按钮都有四态反馈
- [ ] 功能一点没变，数据还在
