## 提示词（中文版）

````text
请在完全保留现有功能的前提下，对这个网页应用做移动端适配，目标是「在 375px 宽的手机上单手就能顺畅使用」。

{{原代码}}

【必须做到的适配项】
1. 视口与缩放：确认有 <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">；输入框字号 ≥ 16px 防止 iOS 聚焦时自动放大页面。
2. 布局：多栏改为单栏；左右分栏改为上下分区或「标签切换」；表格改为卡片流式布局（一行表头信息用小字灰色的 key: value 形式展示，不要用横向滚动的宽表）。
3. 触控友好：所有可点元素最小 44x44px，相邻按钮间距 ≥ 8px；hover 效果补充 :active 状态，手机上点击要有即时反馈。
4. 手势：需要拖拽的地方（看板、排序）补充 Pointer Events 实现，让 HTML5 Drag & Drop 在触屏上也能用；画布/游戏区域加 touch-action: none 防止页面跟着滑动，但页面上其他区域仍要能正常滚动。
5. 键盘遮挡：输入区域的输入框获取焦点时，把该输入框滚动到可视区中部；底部主要操作按钮改为 sticky 或 fixed，并且不要被手机底部安全区遮住（padding-bottom: env(safe-area-inset-bottom)）。
6. 导航：桌面侧边栏改为底部 Tab 栏或可折叠抽屉；长列表添加回到顶部按钮。
7. 弹窗：模态框在小屏上改为从底部弹出的抽屉样式，最大高度 85vh 且内部可滚动，禁止 body 滚动穿透。

【不要做】
- 不要删除任何现有功能
- 不要改变现有数据结构与 localStorage 的 key（否则用户数据会丢）
- 不要更换第三方依赖

【输出】
一句话说明改了什么 → 唯一的 ```html 完整代码块（禁止省略号）→ 3 行说明手机上怎么用。
````

## Prompt (English Version)

````text
Adapt this web app for phones without changing any features. Goal: comfortably usable one-handed at 375px.

{{CODE}}

[REQUIRED]
1. Viewport: ensure <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">; input font-size >= 16px to stop iOS auto-zoom on focus.
2. Layout: multi-column becomes single-column; side-by-side panes stack vertically or switch to tabs; tables become card lists (small gray `key: value` labels instead of a wide horizontally scrolling table).
3. Touch targets: every tappable element at least 44x44px with >= 8px spacing; add :active states alongside :hover so taps feel instant.
4. Gestures: anywhere drag is used (kanban, reordering), add Pointer Events so HTML5 Drag & Drop works on touch; set touch-action: none on canvas/game areas to stop page scrolling while leaving the rest of the page scrollable.
5. Keyboard: scroll a focused input into the middle of the viewport; make the primary action sticky or fixed and clear of the bottom safe area (padding-bottom: env(safe-area-inset-bottom)).
6. Navigation: convert desktop sidebars into a bottom tab bar or collapsible drawer; add a back-to-top button on long lists.
7. Modals: on small screens present as bottom sheets with max-height 85vh, internal scrolling, and body scroll locking.

[DON'T]
- Don't remove existing features.
- Don't change the data model or localStorage keys (users would lose data).
- Don't swap third-party dependencies.

[OUTPUT]
One-line summary -> exactly ONE ```html full block (no ellipsis) -> 3 lines on how to use it on a phone.
````
