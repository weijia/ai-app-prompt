# examples · 参考实现

这里的 HTML 是**按本库规范手写的可运行样例**，用途有三个：

1. **验证规范是否现实** —— 证明「零依赖 / 单文件 / 国内可用」这一套约束能真的跑出可用的东西。
2. **给对话提供风格参照** —— 你可以把它粘给豆包/元宝，说「按照这个页面的代码风格和质量标准，给我做一个 XXX」。
3. **直接改着用** —— 它们是纯静态文件，改完保存即可。

## 文件清单

| 文件 | 说明 | 关键技术点 |
| --- | --- | --- |
| [01-番茄钟.html](./01-番茄钟.html) | 完整应用参考实现 | 时间戳计时、SVG 环形进度、Web Audio 合成提示音、localStorage、导出/导入 JSON、CSS 柱状图、暗色模式、响应式 |
| [02-CDN降级图表示例.html](./02-CDN降级图表示例.html) | CDN 失败降级的最小范例 | 主从 CDN 双地址、onerror 降级到原生表格、图表 resize 处理 |

## 怎么用

双击文件用浏览器打开即可，不需要装任何东西。

想让模型照着写，推荐这样问：

```
请参照下面这个页面的代码组织方式、注释习惯和界面完成度，帮我做一个 XXX。
要求同样保持：单文件内联、零第三方 CDN、localStorage 持久化、中文界面、移动端优先。
（粘贴 examples/01-番茄钟.html 的完整代码）
```
