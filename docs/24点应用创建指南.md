# 24点应用创建指南

> 本文档是一份提示词模板，用于指导 AI 生成符合 [ai-app-prompt](https://github.com/weijia/ai-app-prompt) 规范的 24 点网页应用。

## 使用方式

1. 复制下方「提示词正文」到豆包 / 元宝对话框
2. 将 `{{占位符}}` 替换为实际需求
3. 发送 → 得到 `index.html` → 保存后双击浏览器打开即可

## 提示词正文

```
创建一个 24 点出题器网页应用，要求：

【功能】
- 随机生成 4 个 1–10 的数字，且保证一定能算出 24 点
- 点击按钮换题
- 内置计时器：开始计时 → 算出后点验算 → 自动停表
- 显示用时、本轮题数、最快记录
- 超 60 秒变红提醒
- 一键查看解法

【技术要求】
- 单文件 HTML，CSS/JS 全部内联
- 零依赖，不需要 npm / 构建工具
- 中文界面，移动端友好
- 现代简洁风格：圆角卡片、渐变数字球、统一主色
- 支持 prefers-color-scheme 暗色模式
- 键盘快捷键：空格=开始/换题，Enter=验算

【算法要求】
- 暴力枚举四则运算（含括号），递归合并求值
- 只有能算出 24 的 4 个数字组合才作为题目
- 解法展示用中缀表达式，如 (6-2)×(3+3)=24

【扩展方向】
- 手输表达式实时校验
- 限时挑战模式
- 禁除法/只用加减乘模式
```
